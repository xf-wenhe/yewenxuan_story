# V1 复读修复协议（子代理专用）

## 任务背景

这是中文无限流网文仓库。V1 部分章节存在"模型打转"问题：同一句"碎片感知句"在单章内逐字重复 3-9 次（如 `0428碎片在背包里脉动。`、`0415碎片在背包里发热。`、`金色眼睛在闪烁。`、`叶文轩的脑子没停过。`、`0428螺旋在赵大嘴的背包里脉动。`）。碎片感知是故事的有意母题，但**逐字复读**必须修掉。

**已修复范例：`chapters/volume-1/chapter-87-polished.md`**（第 87 章，已完成）——先读它，理解修复后的效果标准。

## 逐章工作流

对分配到的每一章：

1. 读全文，理解场景与剧情推进。
2. 运行 `node .claude/skills/story-deslop/scripts/check-degeneration.js <章节文件>`，收集 `[blocking]` 行（忽略 `[advisory]`，尤其 `（第X章完）` 标记是仓库惯例）。
3. 对每条 flagged 的复读句：在文件中定位**全部**出现位置。
4. **保留**承载场景节拍的那一处（通常是首次出现，或带变化的那处——如"频率比之前快了""8秒一圈"）。
5. **改写**其余出现处：换成同场景推进剧情的新内容。变化方向举例：
   - 改变感知细节：热度从贴腰侧变成沿手臂爬、脉动变沉/变快/变乱、方向感（碎片在拉向某处）
   - 融入当前动作：脉动打断他的思绪、他的手按向背包、脉动与心跳同频
   - 替换成场景内新观察：关于当前副本/对话/人物的新信息
   - 同一个意思用不同句子结构表达（如"碎片在提醒他"替代"碎片在脉动"）
   - **禁止**：删除节拍不补内容；把对话改掉；新增人物/设定；数字前后矛盾（碎片数量、时间戳、倒计时、8秒一圈等必须一致）
6. 改完后重新运行 checker：`[blocking]` 必须为 0。
7. 校验字数：`python -c "import re; t=open('<文件>',encoding='utf-8').read(); print(len(re.findall(r'[一-鿿]',t)))"`——CJK 必须 ≥3000。不足则用场景内一致的内容补足（不能注水）。
8. 写回文件：必须 `encoding='utf-8'`、`newline=''`，**不得产生 BOM**（`open(f,'w',encoding='utf-8',newline='').write(...)`）。

## 铁律

- **对话逐字保留**：`"大嘴。"叶文轩的声音。"你愿意加入吗。"` 这类对话归属格式是全书惯例，一个标点都不能动。
- **叙事文档逐字保留**：笔记本内容、系统广播（粗体 `**「...」**` 行）、代码块（``` 围栏）——这些是故事内文档，不改。
- **不新增设定**：不发明新角色、新地点、新规则；只基于本场景已有内容改写。
- **数字一致性**：碎片编号/数量、时间戳（2025年10月13日等）、倒计时、8秒一圈、意识一致性 97.3%/97.1%——全部保持。
- **禁用词**（叙述中不得出现）：仿佛、犹如、宛若、如同、深吸一口气、缓缓、不禁、微微、轻轻、淡淡、眼中闪过、嘴角勾起、眉头微皱、眉眼低垂、瞳孔微缩、心中暗道、不由得、不容置疑、不容置喙、不易察觉、显而易见、毫无疑问、不可否认、坚定、闪烁着光芒、狡黠、深邃、凛冽、冰冷、不由自主、情不自禁、自然而然。避免"不是A而是B"句式。
- **不要运行 check-ai-patterns.js**——它的破折号/短段/比喻规则与仓库文体惯例冲突，不在本次目标内。
- **只改分配给你的章节文件**，不要 git commit。

## 报告格式

每个文件返回：
```
文件: chapter-XXX
复读句: <被 flag 的句子>
处置: 保留第N行（原因），改写N处
改写示例: <给出 1-2 个改写前后对照>
CJK: 改前 → 改后
blocking: 改前 N → 改后 0
```
