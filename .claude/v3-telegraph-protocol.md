# V3 电报体重写协议（story-deslop 执行版）

适用：chapters/volume-3/ 中"词——词——词"电报体章节（生成后期风格失控产物，非有意节奏）。

## 1. 任务
把破折号拆词电报体恢复为自然中文叙述。词序是正常中文语序（只是被 `——` 拆碎），恢复 = 重新组织成自然句子，不是创作新内容。

## 2. 电报体特征（需恢复）
- `叶文轩——能——感觉到——自己的——意识` → `叶文轩能感觉到自己的意识`
- `在——往——西——的——方向——开` → `往西开` / `往西的方向开`
- `在——很——轻的。在——很——稳的。` → `很轻，很稳。`（虚词"在——"串全部清除）
- 对话被拆：`"门——关——了。"` → `"门关了。"`
- `塔的——核心——在——慢慢——暗——下来` → `塔的核心慢慢暗下来`

## 3. 恢复规则
- 删词间 `——`，重新组织成自然句：叙述以逗号长句为主（逗号间 8-12 字、整句 20-30 字），不要通篇碎句；保留场景需要的短句节奏（动作/转折压短）
- 对话完全还原自然说话，对话标签低频自然（"说"可保留，不用公式化标签）
- **正文产物不保留 `——`**（story-deslop 原则 4）：犹豫/未尽/打断/拖长用动作、短句、换行、逗号或句号表达
- `……` 也不保留，同样改写
- 保留有功能的 `？` 与少量 `！`

## 4. 必须逐字保留
- 碎片编号（0415/0428/0412/0429、42片/41片）、日期（0415年4月15日、0428年4月28日、1998年4月28日）、时间/倒计时数字
- 粗体系统文档行 `**「...」**`（一字不改）
- 标题行、章末标记 `（第X章完）`、卷末标记（如 `（第三卷完）`）
- 剧情、人物、伏笔：只改"怎么说"，不改"说什么"

## 5. 复读与去 AI 味
- 恢复后同一句子逐字重复 ≥3 次 → 改写（运行 check-degeneration.js 验证 0 blocking）
- 顺带按 story-deslop 三遍法处理残留 AI 味：书面腔、工整排比、解释腔（"他感到…"/"他知道…"式告知）、"不是A而是B"句式、结尾升华
- 禁用词（叙述中不得出现）：仿佛、犹如、宛若、如同、深吸一口气、缓缓、不禁、微微、轻轻、淡淡、眼中闪过、嘴角勾起、眉头微皱、心中暗道、不由得、不容置疑、显而易见、毫无疑问、坚定、深邃、凛冽、冰冷、不由自主、情不自禁、自然而然

## 6. 字数
- 重写后 CJK ≥3000（`python -c "import re; t=open('<文件>',encoding='utf-8').read(); print(len(re.findall(r'[一-鿿]',t)))"`）
- 电报体去碎后字数会降，不足用场景内一致内容补足（深化当前节拍、环境细节、动作、与前文呼应），禁止注水、禁止新增人物/设定/数字矛盾

## 7. 写回与验证
- 写回：`open(f,'w',encoding='utf-8',newline='').write(...)`（UTF-8 无 BOM）
- 行尾保持原文件（CRLF 保持 CRLF、LF 保持 LF）——先探测原文件行尾
- 验证：check-degeneration.js 0 blocking（章末标记 advisory 忽略）
- **不运行 check-ai-patterns.js**（项目指令：与仓库风格冲突）
- **不 git commit**
