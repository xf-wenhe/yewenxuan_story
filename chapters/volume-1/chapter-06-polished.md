# 第六章：蓝

> **字数目标：** 3000字
> **节奏：** 从"紧迫"转为"深度分析"——叶文轩用洞察者能力解剖蓝光标记
> **核心情绪：** 不是恐惧，是求知欲。叶文轩第一次像一个程序员调试一样调试一个"活的"系统标

--

走廊的地板硬得像拆掉外壳的旧电路板。叶文轩靠在墙上，后颈渗出一层薄汗。疗养院的中央空调开得太过分，冷风从头顶的通风口往下灌，把他的外套吹得贴在背上。眼皮沉。但不是困——是精神力被连续的战斗和副本消耗之后留下的空洞。脑子没停。停不下来。

走廊里有一股味道。消毒水和什么别的东西混在一起，像是旧墙纸发潮之后长出的霉味，又像是某种金属被高温烤过之后残留的余味。他分辨不出来。鼻子的灵敏度在下降。精神力透支之后，五感都在退潮。

治疗室的磨砂玻璃门后面透出淡蓝色的光。那束光以稳定的节奏往老周的血管里注入某种东西，每分钟两毫升。叶文轩数了三分钟的滴速。每十二秒一次。三小时后治疗结束，老周还是老周吗。

不清楚。不能只是等。

他在门外地板上坐了将近两个小时。系统面板浮现在视野右上方，半透明的，像一层积灰。他尝试把它调亮，没用。面板的亮度跟着他的精神状态走——精神力越低，界面越暗。倒计时跳到一小时五十二分钟。老周的治疗进度：百分之三十一。叶文轩关掉了任务列表、背包、属性面板，只留着洞察之眼。视野清了许多，走廊的线条变得锐利。灯光在瓷砖表面拉出长长的倒影。

然后他注意到了地面。

老周昏迷前最后站立的位置，地板上有一小片蓝色残留。是溶解传送时从他手臂渗出来的液体，落在地上之后凝固了。指甲盖大小的一块蓝色玻璃，在昏暗的走廊灯光下泛着冷光。像电路板上掉下来的一颗焊珠。

叶文轩蹲下去。

膝盖蹭到了地面上的灰尘。刺骨的冷从膝盖传上来，沿着大腿的筋往上爬。他用指尖碰了碰那片蓝色。

冰的。比疗养院的空气温度低至少五度。触碰的瞬间，指尖传来一阵刺痛。不是皮肤上的，是脑子里的。像是手指蹭到了一块烧红的金属，但痛的不是表皮，是后面那层看不见的东西。他立刻缩回手。指尖在轻微发抖。他把手插回外套口袋里，手指蜷起来，抵着掌心的纹路。

盯着那滴液体看了十秒。然后集中注意力，把洞察之眼的焦点从建筑结构一层层缩小——墙壁、管线、门框被剥离，视野往更细的粒度收拢，直到锁定了那滴蓝色液体。

叶文轩的视野切换了。不是叠加了一层透视，是换了频道。之前看到的是建筑结构层，现在他看到的是一个更细密的网格——像是把显微镜从一百倍调到了一千倍。

蓝色液体的表面呈现出一个规则的几何结构。六边形的网格，精确得不像自然形成的东西，更像一块芯片的电路板。每一个六边形节点都在缓慢闪烁，像在传递信息。叶文轩的心脏跳快了一拍。喉结滑动了一下。

这不是液体。这是结构化的代码，被封装成了液体的形态。

他用洞察之眼追踪蓝色线条的走向——从六边形网格中，线条向四周延伸。他顺着线条追踪，看它们最终连向哪里。原本以为会连向疗养院的电力系统，或者沈知秋的控制节点。以为线条会往下去，往地下室、配电室、走廊的灯光走。

但线条没有往下。线条往上。

沿着管线，沿着墙壁，沿着走廊的线路——蓝色的线一路攀升，穿过一楼、二楼、三楼，最终延伸到了疗养院之外。不是建筑内部的结构。是建筑外部的。

叶文轩顺着线条的终点往上看。在透视图的最高处，线条汇聚成了一个点。那个点在疗养院的上空，在系统面板的天空盒之外，藏在一个他从未注意到的位置。

那个点的形状他看了三秒才认出来。是一个圆。完美的、精确的、由蓝色线条构成的圆。圆的内部有一组旋转的线条——螺旋。螺旋在缓慢转动，他能感觉到它的节奏，每转一圈大约十二秒。

他认识那个螺旋。疗养院副本的走廊壁画上见过。系统的加载界面上见过。第三章的系统广播背景里听过。螺旋等于疗养院的核心标识。

但这个螺旋不在疗养院内部——它在疗养院之上。像是整个疗养院副本是那个螺旋的投影，一个三维模型投射在二维平面上。疗养院是影像，螺旋是本体。

叶文轩的思维在加速。脑子转得飞快。程序员的大脑开始自动拆解这个结构。螺旋是疗养院副本的核心逻辑，蓝光标记是螺旋的子程序，老周手臂上的标记是子程序的执行实例，治疗者是螺旋的守护进程，沈知秋是管理员账户。

整个疗养院不是一个"地图"——是一个运行中的程序。螺旋是内核，其他一切都是外壳。

他把洞察之眼的焦点从螺旋上移开，重新锁回那滴蓝色液体上。想知道液体的代码内容。

六边形网格在视野中放大。每一个六边形都在闪烁，像一块发光屏上的像素。他的视线在网格中游走，像一个程序员阅读源代码——从左上角开始，一行一行地读。

代码不是中文，不是英文，是一种他无法识别的语言。但他能理解它的含义。

不是因为认识这种语言，是洞察之眼在实时翻译。像一个编译器，把未知的代码转换成他能理解的概念。

第一行的含义："意识锚定。目标：人类个体。锚定方式：生物标记。"

第二行："标记激活条件：治疗者注射完成。激活后，目标意识进入系统管辖范围。"

第三行："标记传输协议：当锚定目标的意识活跃度超过阈值时，触发传送。传送目标：治疗室。治疗流程启动。"

他的视线继续往下。第四行。第五行。第六行。

然后他看到了第七行。呼吸停了。

第七行不是翻译出来的——是原文。一种他认识的语言。不是中文，不是英文。是代码。他写的代码。不是疗养院的代码。是另一个系统的代码。他盯着那行代码看了很久。

```
如果 (意识.锚点 == 真) { 系统.传输(目标, "治疗_房间"); }
```

变量名。注释风格。语法结构。连那个多余的 `== 真` 判断都一模一样。

是他的编程风格。完完全全属于他的习惯。

这行代码不是疗养院系统写的。是"另一个他"写的——或者说，是他在某个时间点、某个状态下写的。写这行代码的人和叶文轩有完全相同的编程习惯，连那个多余的 `== 真` 判断都如出一辙。

叶文轩的后背发凉。不是疗养院的系统在标记老周。是他自己写的系统在标记老周。他猛地站了起来。

那滴蓝色液体在透视图中闪烁了一下，然后碎裂了——六边形的碎片散落在地上，消失了。被他的透视消耗殆尽。

他后退了一步。心脏剧烈跳动。不是运动后的跳动，是认知受到冲击后的跳动。

那行代码。`系统.传输`。`治疗_房间`。

他认识那个函数名。不是"认识"——是太认识了。过去十年里写过无数个传输函数，在公司项目里，在业余开源项目里，在深夜调试的时候——写过很多传输函数。

但那行代码的写法太具体了。太个人化了。不是随便写的——是他在有特定习惯的时候才会那么写。

他弯下腰，从地上捡起一小片碎裂的蓝色残片。碎片很小，像指甲盖的十分之一大。用两根手指捏着，对着昏暗的灯光看。碎片在光线下呈现出彩虹色的折射——不是普通玻璃的折射，是全息的。碎片的内部有微小的纹路，像存储介质的表面。他把碎片放进口袋。碎片的边缘很锐利，抵着指腹，有一点微弱的刺痛感。

然后打开系统面板——那个他十年来每天都要面对的终端。新建了一个文本文件。敲下几行。

```
蓝光标记 = 系统子程序
核心代码风格 = 叶文轩本人
结论：疗养院系统的底层代码，由"叶文轩"编写
```

盯着那行结论看了很久。不是"未来的叶文轩"。不是"另一个叶文轩"。就是叶文轩——他在某个时间点、某个状态下，写下了疗养院系统的底层代码。

可他今年三十七岁。一个失业的程序员。现实中写过前端脚本语言、编程语言脚本、数据查询语言查询。从未写过什么"系统底层代码"，从未接触过任何"无限世界"的技术。

除非，除非那行代码写的不是"未来的他"。是过去的他。

--

叶文轩在地板上坐了很久。阿梅站在旁边，没有说话。小樱靠在墙上，已经睡着了——精神上的疲惫比身体上的更耗人。他把注意力拉回当前。

面板上的倒计时：一小时三十二分钟。老周的治疗进度：百分之四十一。

需要救老周。但不是用暴力。冲进去抢人？控制台上那个红色按钮的后果未知，不敢碰。老周手臂上的蓝色管子连着注射器，注射器连着控制台，控制台连着整个治疗系统。硬来的话，老周会死。需要一个更聪明的方法。

用洞察之眼重新扫描治疗室。这次不是扫描建筑结构，是扫描系统结构——想知道治疗系统的逻辑。

透视图中出现了新的线条。不是建筑线条，是逻辑线条，像一个数据流图在房间里流动。

输入：患者进入治疗室，治疗系统激活。处理：蓝色液体注入，代码写入意识，记忆修改。输出：患者离开治疗室，记忆被修改。

流程是一个管道。标准的、线性的、可预测的处理。盯着这条逻辑管道看了十秒，然后看到了管道中间的一个节点。一个存储节点。标签是 `临时_记忆_备份`。心跳加速了。那声跳动静得奇怪，像是肋骨内侧被什么东西撞了一下。

治疗系统在修改老周的记忆之前，先做一个备份。把原版记忆存起来。覆盖。然后——按照流程设计——治疗结束后，应该把备份恢复。

但如果恢复步骤出了错呢？如果备份没有被恢复呢？老周就永远失去了原来的记忆。把信息记在脑子里，开始追踪那个 `临时_记忆_备份` 节点——想知道备份存在哪里。

逻辑线条从存储节点延伸出去，不是往治疗系统走，是往疗养院的上层。和蓝光标记的线条走的是同一条路——往上去，往疗养院之外去，往那个螺旋去。备份被存在螺旋里。螺旋等于疗养院的核心，等于疗养院的。"云服务器"。叶文轩站起身。膝盖有点麻，站起来的时候晃了一下。

"阿梅。"阿梅看向他。"我们有一个小时三十二分钟。"他说，"这时间够做一件事——找到疗养院的出口。应该在地下室的某个地方。"

他看向走廊深处。螺旋走廊往左转，转完之后是一个大厅。大厅的透视图中有一个白色的光点——在所有红蓝灰色的标记中，那个白点是唯一的暖色。出口的标记。带领三个人往大厅走去。走廊两侧的照片在灯光下泛着冷白的光，那些患者的脸在墙上沉默地注视着他们，像是在目送，也像是在警告。走到大厅门口时，停了一下。

大厅的正中央有一张椅子，旁边一张小桌子。桌上放着一台老式收音机——黑色外壳，旋钮式调频，天线上缠着一圈红绳。

收音机是开着的，但没有声音。不是"没有广播"——是。"有声音，频率调到了空白"。嘶嘶的、沙沙的调频噪声，像是深海里的回声。叶文轩走过去，低头看着收音机。

旋钮的位置不是随机的——被精确地调到了某个特定的频率。不是任何广播电台。是系统的频率。用透视扫了扫收音机的内部。

电路板和普通收音机不一样。电路板上有蓝色的纹路——和蓝光标记的六边形网格一模一样。

收音机不是用来听广播的。是用来接收蓝光标记信号的。叶文轩的后背涌上一股凉意。

疗养院的每一个角落都在监控蓝光标记。收音机是接收器，治疗室是处理站，螺旋是服务器。整个疗养院是一个完整的系统——从标记、接收、处理到存储，一条龙。

他转身离开大厅。阿梅和小樱跟在他身后。

走出大厅的最后一秒，回头看了一眼那台收音机。
沙沙的噪声中，隐约听到了一个音节。

不是系统的广播。不是沈知秋的歌声。是一个人声。

一个他在现实中非常熟悉的声音。咳嗽声。叶文轩猛地转身。

但大厅里只有那台收音机在沙沙作响。阿梅和小樱在等他。走廊两侧的患者照片在灯光下沉默地注视。

那声咳嗽可能是幻听。可能是噪声中偶然的频率巧合。可能是想象力在疲劳中开了个玩笑。但叶文轩不这么认为。

他走向地下室的方向——那扇标记着白色光点的门。开门之前，对阿梅和小樱说了一句话。

"我们去救老周。但我不去'救'——我去'拆'。"

阿梅看着他。小樱看着他。

"拆什么？"小樱问。

叶文轩没有回答。推开了那扇门。

门后是一条更长的走廊。走廊的尽头有一扇门——没有锁，没有密码，没有标记。

只有一个符号。一个螺旋。和透视图中看到的一模一样。

（第六章完）
