# 第七章：拆

墙壁的温度接近冰点。叶文轩的指腹贴上去的瞬间，皮肤上起了一层细密的鸡皮疙瘩。灰白色的表面光滑得反常，像某种高性能聚合物的涂层。但光滑底下藏着一丝黏滞的拖拽感，像摸到了没有干透的树脂。指腹在墙面上停了五秒，沾了一层几乎看不见的油膜，泛着极淡的、工业润滑剂的气味。

走廊里很安静。能听见自己的呼吸声，还有某种极其微弱的低频嗡鸣，从墙壁深处传出来，像一台巨大机械的轴承在空转。叶文轩闭上眼睛，让耳朵在安静里多待了三秒。嗡鸣的频率很低，接近次声波，耳朵几乎听不见，胸腔在跟着颤动。他重新睁开眼，激活了洞察之眼。

墙壁的透视结构呈现为双层。外层灰白色材料，厚度约三厘米，无缝拼接。内层是密密麻麻的管线网络，像一株在地下疯长的根系，布满了整面墙体。蓝色的液体在管线中流动，流速均匀，不急不缓。和蓝光标记里的液体是同一种东西。整栋疗养院的墙壁里全是这种液体。整栋建筑就是一根输血管。

叶文轩收回手，指腹在指尖间搓了搓那层油膜。"阿梅。"他转过脸。

阿梅的手指在衣角上绞了三圈，指节泛白。她的喉结滑动了一下，像是在组织语言，又像是在克制什么。"螺旋。往下走的时候一直在转。转了多少圈，我数不清了。大约三圈？"

叶文轩点头。视线移回透视图中。螺旋走廊从入口开始顺时针往下转了正好三圈，每一圈的长度递减约二十米。第三圈的尽头就是螺旋的中心。那扇刻着螺旋符号的门立在那里，纹丝不动。

他蹲在螺旋走廊的起点，后背抵着墙壁，打开了系统面板。新建了一个文件。文件名是`救援_计划.文档`。用代码注释的格式，他写下了营救计划的框架。

```
// 目标：从治疗室中救出老周
// 约束1：治疗进度剩余约2小时
// 约束2：治疗系统运行时不能硬闯（后果未知）
// 约束3：蓝光标记有传送机制（剩余约1.5小时）
// 策略：？？？
```

策略那一行他留了空白。思路太多了，需要筛选。

叶文轩合上系统面板，闭上了眼睛三秒。脑子没停。他把自己当成了这个副本的玩家兼调试器。不仅要通关。还要找到系统逻辑里的漏洞。在漏洞里救出一个人。

走廊里的低温往骨头缝里钻。后背贴着的那面墙，冰意透过外套渗进了肩胛骨。他蹲得太久，左膝开始发麻。右手的食指和中指无意识地交替敲击着大腿外侧的布料，一下，两下，三下：程序员的节奏，敲代码的时候就是这个频率。

首先理清治疗系统的完整流程。治疗者注射蓝光标记，玩家被标记。标记激活，玩家被传送到治疗室。治疗系统启动，蓝光液体注入，记忆被覆盖。治疗结束，玩家离开治疗室，记忆已经被修改。

关键节点在第三步。记忆修改的过程需要一个时间窗口。系统面板显示老周的治疗需要三小时。在这三个小时里，蓝光液体持续注入，记忆持续被覆盖。但他能中断第三步。

他睁开眼。走廊的灯暗了一截，头顶那盏频闪的灯灭了，整条走廊掉进了半明半暗之间。透视图中，墙壁里的蓝色管线还在流动，不受灯光的影响。叶文轩用透视追踪了一条管线。从走廊墙壁出发，沿着螺旋往下走，穿过三层螺旋结构，每一层旋转角度递减约三十度。最终汇聚到螺旋的中心。中心就是治疗室。管线从四面八方汇聚到治疗室，像十四根输液管同时插在一具躯体上。

但管线不是单向的。叶文轩逐层放大透视倍率。每条管线在靠近中心的地方都有一个阀门。阀门在透视图中是一个小圆点。蓝色代表开启。灰色代表关闭。

他现在的位置到螺旋中心的距离大约六十米。沿路有十二个阀门，其中七个蓝色开启。治疗液体的供应通道目前是全开的。

叶文轩的指尖在虚拟面板的屏幕上停住了。如果关掉这七个阀门呢？治疗液体的供应中断。治疗系统失去燃料。治疗进程暂停或者终止。老周的记忆不会被覆盖。然后安全地进入治疗室。把老周带出来。

方案有了。现在的问题是：阀门在哪里？

走廊太暗了。透视图中的小圆点颜色不够明显，在灰白墙面的底图上几乎辨认不出来。他需要更亮的灯光。但疗养院的灯光是沈知秋控制的，他不能指望灯光配合他。

他看向小樱。

小樱正靠着走廊的另一面墙坐着，闭着眼睛，嘴唇动了动。叶文轩走过去的时候她才睁开眼睛，睫毛在脸上投了一道细细的影子。

"小樱，"他蹲下来，视线和她平齐，"你能感觉到方向吗？能感觉到哪边有灯、哪边没灯？"

小樱愣了一下。她的瞳孔在暗光里显得格外大，像两颗浸在水里的玻璃珠。"能。灯的地方，感觉比较轻。没灯的地方，比较重。"

"前面哪边比较轻？"

小樱闭上眼睛，鼻翼颤动了一下。她的嘴唇动了一下，像是在默数。五秒后她睁开眼，指向螺旋走廊的下方。"往下去的那段，右边比较亮。有灯。"

叶文轩看向她指的方向。透视图中，那条走廊右侧确实有几盏灯的标记。蓝色的光点比左侧密集，像一组提前排好的路标。

"阿梅，"他站起来，"你和我走右边。小樱，你留在这里。如果我们十五分钟内没有回来，你一个人继续往螺旋中心走。出口在中心的后面。"

小樱的嘴唇动了一下，想说什么。但她最终点了点头，没有开口。她的眼神在他和阿梅之间停了半秒，然后移开了。

叶文轩和阿梅沿着螺旋走廊往下走。右侧果然有几盏灯。昏黄的，闪烁的，像一个人在喘气。灯光照亮了墙壁，叶文轩在灯光范围内清晰地看到了管线上的阀门。第一个阀门。左侧墙壁，距离约五米。灰色，关闭状态。跳过。第二个阀门。右侧墙壁，约八米外。蓝色，开启状态。目标。

叶文轩走过去。阀门的外形是一个圆形金属盘，嵌在墙壁里，大小刚好能用一个手掌覆盖。金属盘表面有一圈细细的凹槽，像是工具留下的刻痕。手指按上去是凉的，和蓝光液体的温度一样。他顺时针旋转了九十度。阀门发出一声轻微的咔哒声。从蓝色变成了灰色。阀门二号，关闭。

叶文轩和阿梅继续往下走。第三个阀门，左侧墙壁，蓝色，开启。第四个，右侧墙壁，蓝色，开启。第五个，左侧墙壁，已经是灰色，跳过。

他们在螺旋走廊中一层一层往下走。每转一圈，走廊就窄一点，灯光就暗一点。空气变得粘稠，像是裹了一层看不见的膜。脚步声在螺旋结构里产生回声，一下，两下，三下，叠在一起，辨别不出脚步的远近。叶文轩用透视标记出了每一个阀门的状态。蓝色的是目标。灰色的是安全的。

转第二圈的时候，他们遇到了第一个治疗者。叶文轩提前在透视中看到了它的蓝色线条。从前方十米处的拐角滑过来。他一把拉住阿梅，两人瞬间贴在走廊左侧的墙边。叶文轩的身体压在墙上，背部传来那道熟悉的冰凉触感。阿梅的肩膀撞到了他的胸口，她的呼吸喷在他的下颌线上，短促而灼热。

治疗者的白大褂从拐角处滑出来。面部模糊，像一张没有被画完的画。动作机械，关节处的弯曲角度不自然。身上弥漫着浓烈的消毒水味，从远处就能闻到。刺鼻的，没有温度的，像手术刀划过皮肤的气味。它在离他们两米的位置停了下来。

叶文轩屏住了呼吸。阿梅的身体绷紧了。他能感觉到她肩膀传来的细微颤抖，骨头在皮肉下面打着颤，像冬天里冻透的树枝在风里抖。

治疗者的面部朝向他们。但它没有看到他们。它的视线似乎只沿着固定的巡逻路线移动，对贴在墙边的两个静止目标没有反应。叶文轩默默数了三秒。一。二。三。治疗者的头部慢慢转过去，重新开始移动，向右，沿着巡逻路线，消失在下一个拐角。两人继续往下走。

叶文轩注意到一件事。治疗者在关闭阀门后经过的时候，动作变慢了。这条走廊的灯是亮着的，问题出在阀门上。阀门关闭影响了管线中的液体流量，而治疗者的能量来源是液体。

关阀门等于削弱治疗者。叶文轩把这个发现记在了`救援_计划.文档`里。

```
// 发现：关闭阀门会削弱治疗者
// 推论：治疗者依赖蓝光液体供能
// 推论2：关闭全部阀门 = 治疗者瘫痪
```

他们转完第三圈的时候，七个阀门全部关闭了。每关一个阀门，叶文轩都能在透视中看到治疗者的蓝色线条移动速度略有下降。到第三圈结束时，最后那只治疗者的移动速度只有最初的六成。

叶文轩站在螺旋走廊的最低点，面前就是那扇刻着螺旋符号的门。他把手放在门板上。门是温的。和之前一样。他推开门。

--

治疗室比他想象的小，是一个紧凑的白色房间，大约十平方米，不是那种巨大的手术室。天花板上有一盏灯，灯光是蓝色的，从头顶浇下来，把一切都泡在一种深海般的色调里。

手术台在房间的正中央。老周躺在上面，左臂上连着那根蓝色管子。管子连着墙上一个悬挂的装置，像大型静脉输液架，但输液袋里装的是一团蓝色的光，不是液体。半透明的，流动的，像被封在琥珀里的一小块天空。封装在透明容器里，通过管子连到老周的手臂上。

叶文轩的洞察之眼扫过整个房间。墙上有一个控制面板。三个按钮，两个指示灯，一个显示屏。显示屏上的文字写着：

> **「患者编号：003。治疗进度：百分之六十七。剩余时间：一小时十一分钟。治疗状态：正常。」**

百分之六十七。比之前看到的百分之四十一快了很多。蓝光液体的注入速度在加速了。叶文轩抬起手腕，看了看系统面板上的倒计时。他和阿梅在螺旋走廊里花了大约四十八分钟。剩下的时间比预计少。

叶文轩走到控制面板前。三个按钮。红色的，标签是"紧急终止"。黄色的，标签是"调整剂量"。绿色的，标签是"确认完成"。

叶文轩盯着红色按钮看了三秒。紧急终止。听起来很简单。按下去，治疗停止，老周得救。但他想起了程序员的基本原则：永远不要在生产环境中执行一个你无法预测后果的操作。

这扇门后面有什么后果，他不敢打开看。可能会安全停止治疗。也可能会触发系统的应急协议，比如直接删除患者。或者触发沈知秋的某种反应，首领战提前开始。他不能赌。

叶文轩看向了黄色按钮。"调整剂量"。

如果减少剂量呢？降低蓝光液体的注入速度？让治疗进度变慢？给他更多时间去研究，去准备，去找到真正安全的救出方法？叶文轩的手指放在了黄色按钮上，但他没有按下去。

他先打开了洞察之眼，扫描了控制面板的内部结构。想看看每个按钮到底连接着什么。

透视图中，三个按钮的内部线路清晰地呈现出来。红色按钮连到治疗系统的总开关。按下等于彻底切断。透视图中，红色按钮的线路末端有一个红色的闪烁标记：系统的安全锁。按下去之前，系统会弹出确认框。但如果玩家在弹窗出现时犹豫超过五秒，系统会自动执行默认操作。默认操作是什么？透视没有显示。那条线路在安全锁之后断开了，像一张被裁剪了一半的设计图。

黄色按钮连到流量调节阀。按下等于降低液体流速百分之五十。透视图中，这条线路干净利落，没有安全锁，没有弹窗，直接连到墙上的输液装置。后果可预测。治疗进度减速。

绿色按钮连到完成确认。按下等于告诉系统治疗已经完成。透视图中，这条线路通向整个疗养院的中央处理器。按下绿色按钮等于提交一个信号："治疗结束"。信号到达沈知秋的终端，触发出院流程。后果是治疗终止，患者出院。但老周的记忆已经被覆盖了一部分了。按绿色按钮等于接受修改后的老周。叶文轩收回了手指。

三个按钮。三个选择。三个不同的后果。没有一个是他能安全选中的。

这是一个绕过这三个按钮的问题，不是选哪个按钮的问题。

叶文轩重新审视了整个房间。透视扫过手术台、输液架、墙壁、地板、天花板。金属和白色涂层层层剥开。然后在手术台的下方，他发现了一样东西。

一个小盒子。嵌在地板里，只有指甲盖大小。没有按钮，没有屏幕，没有标记。但在透视图中，它的内部有一个蓝色的光点在闪烁。和阀门、和标记、和疗养院上空的螺旋同步旋转。转速约十二秒一圈。

叶文轩蹲下来，用指甲的边缘撬开了那个小盒子。透明的立方体。内部悬浮着一个微型的螺旋，和疗养院上空的那个螺旋一模一样，只是缩小了无数倍。微型螺旋在他的掌心里旋转，和外面的螺旋保持着完全一致的节律。十二秒一圈，不多不少。

叶文轩把这枚微型螺旋握在掌心里。它比看上去更轻，几乎没有重量。沈知秋的控制台和按钮都是外壳。真正的控制逻辑在这枚螺旋里。如果他能修改这枚螺旋的逻辑呢？

但他不知道怎么修改。洞察之眼能读结构，但不能写。透视是他唯一能用来与系统交互的方式，但它只有输出通道，没有输入接口。像一台只能接收信号的收音机，不能用来广播。

叶文轩把微型螺旋放回盒子里，盒子塞进了外套口袋。然后他做了一件可能很蠢、但作为一个程序员无法不做的事。

他蹲在控制面板前，打开了系统面板的文本编辑器。在编辑器里敲下了一段代码。

```
// 修改疗养院治疗系统参数
// 目标：降低治疗液体流速至10%
// 方法：通过洞察之眼的透视接口写入
// 注意：此操作未经系统授权

函数 降低流速(目标_阀门, 百分比) {
  阀门_2.状态 = "关闭"; // 已完成
  阀门_3.状态 = "关闭"; // 已完成
  阀门_4.状态 = "关闭"; // 已完成
  阀门_5.状态 = "关闭"; // 已完成
  阀门_6.状态 = "关闭"; // 已完成
  阀门_7.状态 = "关闭"; // 已完成
  阀门_8.状态 = "关闭"; // 已完成

// 所有供应阀门已关闭
  // 治疗液体流量 → 0%
  // 治疗进度 → 暂停
}
```

他写完之后盯着这行代码看了五秒。这不会真的运行。系统面板的文本编辑器只是一个笔记功能，他写的代码不会被系统执行。他只是在记录自己做了什么决定。

但写完这段代码之后，叶文轩感觉到了一丝荒谬。他在用一个"假的代码编辑器"写一段"不会执行的代码"来"记录"一个"不会生效的操作"。整个疗养院是一个程序，但他手上只有一个记事本。一个在真正的代码世界里会被同行笑话一百次的解决方案。他关掉了编辑器。

叶文轩走到手术台前。老人平静地躺着，呼吸均匀。脸上的皱纹在蓝色灯光下显得格外清晰。颧骨上有一颗痣。左耳垂上有个小小的穿孔。叶文轩认出了这张脸。一个真实的人的脸，做过四十二年医生的老人，有三个孙子的爷爷，今天早上还跟他说"小叶，保重"的人。

叶文轩的喉结滑动了一下。拳头松了又攥，攥了又松。他不能在这里等。他需要去找出口，找到真正能关掉这个系统的方法。治疗室的三个按钮都不安全，但也许外面有他没看到的东西。

他蹲下来，凑到老周的耳边。老人呼吸很轻，像一池快静止的水。叶文轩的嘴唇动了动，然后压低了声音：

"等着我。我去拆这个系统。"

然后他转身离开了治疗室。

--

叶文轩走出螺旋走廊的时候看到了那行刻字。是用指甲，或者某种更尖锐的东西，在墙壁上划出来的，不是笔写的，也不是喷漆喷的。刻痕很深。白色的墙壁上，刻字的边缘有细细的裂纹，像是划刻的人用了很大的力气，最后一下几乎要把整块墙皮掀起来。

字只有五个。不要相信治疗。

叶文轩盯着这行字看了很久。字迹潦草，但有力。划刻的时候是在嘶吼，用最后一点力气留下一个警告。

叶文轩的洞察之眼扫过刻字的边缘，没有发现系统痕迹。刻字不在系统的任何记录中。是某个玩家刻的，或者某个被治疗的人，在意识被覆盖之前，用指甲在墙上划下了这行字。

四个字堵在喉咙口。"不要相信沈知秋"是敌人，可以防备；"不要相信这个副本"是陷阱，可以避开。但"不要相信治疗"，治疗等于疗养院的核心规则，等于系统的底层逻辑。有人在警告后来者：系统给你们的"帮助"，都是在骗你们。

叶文轩把食指放在刻字上。他能感觉到刻痕边缘的粗糙。刻字的人留下的粗糙，不是墙壁的。手指碰到刻痕的一瞬间，后颈的汗毛竖了起来。一种纯粹的恐惧顺着脊椎往上爬。对治疗本身的恐惧，对那根蓝色注射器的恐惧，对被改写的恐惧。

他收回手。指尖残留的触感像一小块冰，冷得他想把它塞回口袋里暖和一下，但口袋里什么也没有。

他转身往出口的方向走。螺旋走廊的尽头，那扇门上的螺旋符号在蓝色灯光下旋转。脑子没停。

五个刻字。一个微型螺旋。一盒蓝色液体。老周在手术台上。治疗进度百分之六十七。还剩一小时十一分钟。

所有线索指向同一个方向。疗养院是实验室，不是副本。他是被试，不是玩家。

这个念头冒出来的时候，他的脚步没有停。但他呼吸的节奏乱了一下，就一下。走廊尽头的螺旋符号转了一圈，十二秒，不多不少。和他口袋里的微型螺旋同步。

不。现在想这个太早了。他还需要更多证据。需要亲眼看到更多东西才能把"可能是"变成"确实是"。程序员的毛病：在没有跑完所有断点之前，他不给任何变量定性。

叶文轩走出了螺旋走廊。一楼大厅出现在眼前。空无一人。空气里有消毒水味，淡了一些，但还在。那股味道像一层薄膜裹在喉咙上，吞咽的时候喉咙发涩。前台后面的椅子上有一本登记簿。封皮上写着"入院登记"。叶文轩走过去，翻开了登记簿。

第一页的日期是1997年3月1日。第一个登记的患者名字是王建国。诊断：焦虑症。第二个患者：李秀英。诊断：抑郁症。第三个患者：张明远。诊断：精神分裂症。

叶文轩一页一页地翻。从1997年翻到1998年。每一页上都有患者的名字、诊断、治疗方案。笔迹是同一个人的。工整的，冷静的，像外科医生写手术方案的字迹。沈知秋的字迹。

翻到最后一页的时候，叶文轩看到了一个不属于这个登记簿的东西。一张便签纸，夹在登记簿的最后一页和封底之间。便签纸很小，是撕下来的一角。纸张发黄，边缘参差不齐。上面用铅笔写了一行字，字迹潦草，像是写的人手上在抖。

"她不是在治疗病人。她在收集他们。"

叶文轩把便签纸折好，放进了口袋。纸张的边缘蹭过他的指尖，很粗糙，像草纸。他抬起头，看向疗养院的大门口。大门敞开着。门外是夜晚的草地，草叶上覆着一层薄霜，被大厅里的光照得发白。远处有一棵孤零零的树，枝干在夜风里摇晃。

大门口处，透视形成了一个白色的光点。和其他蓝色的、红色的标记完全不同。系统标注的出口。

但他没有往出口走。他回头看了一眼身后的走廊。螺旋的方向，地下室的方向，老周的方向。叶文轩咬了咬牙，后槽牙研磨的声音在安静的大厅里清晰可闻。

他转身走向走廊深处。往地下室走。

老周还在那里。治疗进度百分之六十七。还有一小时十一分钟。

叶文轩要去拆这个系统。

（第七章完）
