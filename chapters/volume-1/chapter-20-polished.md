# 第二十章：原型

鬼屋比叶文轩想象的干净。墙壁上没有漏灰的裂缝，地砖上没有积水反光。骷髅图案贴得整齐，塑料蜘蛛网挂在拐角没沾灰，骸骨捏上去是橡胶的，弹性很假。廉价恐怖：粗劣道具堆出来的心理压迫。走廊里的低音喇叭循环播放拖长的呻吟声，每隔三秒换一个频率。低频在胸腔里沉一下又浮上来，像有什么东西贴着肋骨内侧敲了一下。

叶文轩扫了一眼内部结构。布局是个迷宫。走廊分叉、拐弯、有时绕回原地。墙壁里嵌着弧面镜，银灰色表面反射出不规则的光斑。透视扫过去，镜子不是普通玻璃，反射的是意识层能量，不是可见光，透视图中显示为异常密度层。镜子的用途很明显：照记忆，不是照人。

他在第一面镜子前站了一秒。镜子里映出他的脸，后面跟着一个模糊的人形轮廓，姿态和他一模一样，只是边缘发虚，像信号不好的画面里拖出来的残影。他猛地转身。身后什么都没有。只有空荡荡的走廊，低音喇叭在远处嗡着，频率又变了。再看镜子，轮廓消失了。

记忆镜像。镜子在反射他的记忆残影。

赵大嘴也照了一下。他身后的轮廓不是他自己。穿橙色夹克的人，背影，走在月光下。那个人走了几步，停下来，像在等什么人。赵大嘴盯着那个背影看了很久。喉结滑动了一下，咽唾沫的声音在安静的走廊里清晰可闻。

"那个，"他的声音很轻，不像平时那么响，"是我吗？"

叶文轩没回答，拉着他往迷宫深处走。走廊拐弯处的温度骤降，裸露的皮肤上浮起一层薄汗。冷气从地板下面渗出来，皮鞋踩在瓷砖上感觉不到回声。

"别看镜子太久。"他说，"在消耗精神力。透视也能看到它们。别碰。"

赵大嘴点头。脚步慢了，在消化刚才看到的画面，不是害怕。嘴唇抿成一条线，眉心有一个很浅的褶皱。

透视在迷宫深处标记了一个蓝色光点。硬币的位置。光点藏在一面大镜子后面。

他们走到那面镜子前。两米高，一米宽，银色表面在月光下发亮，边框上积着一层薄灰。周围的墙壁上贴满了彩色照片，纸角卷了起来，像是贴了很多年，胶带的黄色边沿已经脆化开裂。叶文轩走近看。空气里有旧纸张的味道，还有隐约的霉味，从照片背面散发出来。他抽了抽鼻子。

照片上是他和赵大嘴。不是疗养院里的样子，不是现在穿的这身衣服。照片上的叶文轩穿着深蓝色风衣，赵大嘴穿着黑色夹克。两个人站在一个空白的地方：没有建筑，没有天空，只有螺旋线条在背景里不紧不慢地转着，像时间被拧成了绳，一圈一圈绕在背景上。照片右下角有日期。

2147年6月12日。

叶文轩的后背凉了。后颈的汗毛竖起来，皮肤下面一阵阵发紧。

2147年。比2024年晚了一百二十三年。照片上是未来的他和未来的赵大嘴。他现在等级1，不可能活到2147年，除非系统里的时间不是线性的，除非系统里的"寿命"和现实世界的计时方式不一样，除非他在2147年还活着，以某种他不理解的方式存在。

脑子里有一个开关咔嗒按下了。很多碎片开始往同一个位置拼。

他的手指碰了碰镜面。镜子是温的。和疗养院的螺旋门一样，温度从镜面深处渗出来，像有什么东西在镜子后面呼吸，温热的气息抵着玻璃。

他用力一推。镜子动了。是个活动的暗门，不是固定在墙上的。铰链没发出声音，像是上了油。后面是一个不到五平米的小房间，桌上放着一台旧电脑。

是真正的物理电脑，九十年代风格的台式机，不是系统的虚拟界面。老式CRT显示器凸出一大块，笨重的米白色主机，键盘按键磨损严重，键帽上的字母磨得发白。电源灯亮着，电脑在运行，散热风扇发出细微的嗡鸣，低频震动从桌面传上来，透过鞋底感觉到轻微的麻。

叶文轩走过去。手指碰到主机壳，金属表面有静电的刺痛感。他用指腹擦了擦机壳侧面，一道浅灰色的划痕，长度和手指差不多。

屏幕上是个代码编辑器。真正的代码编辑器，不是系统界面。深色背景，浅色文字，编辑器打开了一个文件，文件名显示在标题栏里。

系统核心代码。

叶文轩盯着那行字。文件名用了他大学时的编程语言。是他熬夜写课程作业时用的那套，不是系统分配的那个花哨脚本格式。缩进两个空格，变量名用下划线连接，函数名用小写加驼峰。

他的手指落在键盘上。键盘的手感和他用了十年的键盘一模一样。键帽的磨损程度、按键的阻力、空格键上被磨得发亮的位置，全对上了。像把手伸进了自己过去的一只旧手套里，手指知道每个褶皱在哪儿。

他敲了一下空格键。光标闪烁了一下。然后他开始读代码。

注释是中文。他的母语。变量命名方式、缩进习惯、注释格式，甚至那些多余的空格和无意义的临时变量名，全是他自己的风格。每一行都在说：这个人懂他。懂到害怕。

第一行注释写着：

```
# 系统核心逻辑 版0.1

# 作者：叶文轩
# 日期：1998年4月28日
# 备注：这是一个实验性的闭环系统。目标：测试意识在循环中的稳定性。
```

叶文轩的手指停在键盘上。

1998年4月28日。0428。疗养院的密码。保险箱的密码。那个日期。

1998年4月28日，他写下了这个系统的第一个版本。但他2024年才出生，至少他这么认为。12月3日。身份证上的日期，他记得清清楚楚，刻在脑子里的。

除非他的记忆是错的。除非系统修改过他的记忆。他的"2024年"不是真正的出生年份。他整个人生，从出生到进入系统，可能都是系统植入的脚本，写在某个文件里，和系统核心代码放在一起。一整套经历，一套身份，一套他深信不疑的过去，全是被写入的代码。

他喉咙发紧。掌心渗出细汗，手指肚上亮晶晶的。

他继续往下读。代码的第二部分是一个邮件发送模块，已经写好但从未执行。脚本的注释写着"未发送的邮件"，收件人是"过去的叶文轩"，主题是"闭环笔记 #1"。触发条件写得清清楚楚：意识活跃度 > 200%。

邮件内容很短。

> 「如果你收到了这封邮件，说明闭环已经开始运转了。
> 你会在疗养院里遇到沈知秋。她的痛苦是闭环的第一个节点。
> 你会遇到赵大嘴。他是你的锚点。不要伤害他。他是你的另一半。
> 你会遇到朵朵。她是沈知秋的女儿的回声。记住她。她是你打破闭环的钥匙。
> 0428是一个重要的日期。4月28日。系统启动的日子。
> 你会忘记这封邮件。系统会清除你的记忆。但邮件会留在这里——在游乐园的鬼屋里，在系统的原型代码中。
> 当你再次看到这封邮件的时候你会明白一切。
> 祝你好运。
> ——来自2147年的叶文」

最后一行只写了一个名字。叶文。

2147年的叶文轩没写完自己的名字。

叶文轩盯着那行截断的署名。三个笔画，最后一横悬在半空，没落下去。

2147年。照片上的日期。邮件的时间戳。三个来自未来的证词同时摆在他面前，指向同一个结论。

未来的叶文轩写了这封邮件，寄给过去的叶文轩。未来的叶文轩知道过去会发生什么，疗养院、沈知秋、朵朵、赵大嘴、0428，他全知道，因为他已经经历过了。

这是回忆，不是预言。一封用回忆写成的邮件，寄给了写下这份回忆之前的自己。

但邮件从未发送。脚本状态显示："待发送"。触发条件：意识活跃度 > 200%。叶文轩的意识活跃度现在是+340%，超过了阈值。邮件应该已经发出去了。

他的系统面板里没有任何新邮件提示。邮箱是空的。收件箱、发件箱、草稿箱，全空。连已发送文件夹都没有。

为什么？

透视扫过邮件脚本的代码逻辑。发送函数里有一个条件判断。

```
如果 (意识.锚点 == 真) { 发送_邮件(); }
否则 { 日志("邮件待发。等待锚点激活。"); }
```

邮件发送的前提是：意识锚点 == 激活。

他的意识锚点是什么？叶文轩想不起来了。他还没激活过任何锚点。赵大嘴是候选锚点，但他们还没完成绑定激活。系统显示"不可解除（本次副本期间）"，但锚点激活需要另一个条件。那个条件是什么，系统面板上没有写。

邮件卡在发送队列里，因为锚点还没激活。

叶文轩的后背涌上一股凉意。后颈的汗全竖起来了。

2147年的叶文轩预见到了这个问题。1998年的自己不会立刻激活锚点。所以他在代码里留了一个延迟，把邮件卡在队列里，等锚点激活时自动发送。

一封定时邮件。2147年写好，设定在锚点激活时发送，收件人是1998年的自己。

他同时是寄件人和收件人。同时是作者和读者。

透视扫过屏幕右上角。系统时钟显示。

2147年6月12日 03:17:42。
叶文轩愣了。

这不是游乐园的表面时间。月亮还在天上，星星还在闪。但电脑时钟是2147年的凌晨三点。游乐园的系统时间是2147年。

那张写着"1998年4月15日"的疗养院闭院报纸，是2147年的报纸，印着2147年的日期，内容却在报道1998年的事。

时间线不是线性的。1998年、2024年、2147年，三个年份在闭环里是同一个点，只是从不同角度看到的不同切面。像一根管子从不同的两头往里看，看到的是同一个截面。

他在2147年。他在读2147年的自己写的代码。他在读未来的自己写给过去的自己的邮件。

脑子嗡的一声。耳鸣持续了大概两秒，像有人在他耳朵里敲了一下钟。

需要冷静。用程序员的思维拆解这个认知地震。

系统的核心代码是他在1998年4月28日写的，但1998年4月28日的"叶文轩"是谁？一个37岁的人不可能在1998年写代码，那时候他还没出生。

除非他没有出生过。除非2024年不是他的出生年份。除非他的整个身份，叶文轩，37岁，失业程序员，离异，有一个12岁的女儿，全是系统植入的脚本，写在某个文件里，和系统核心代码放在一起。

2147年的叶文轩写了这封邮件，寄给1998年的自己。邮件卡在发送队列，等锚点激活。

时间线是闭环。三个年份是同一个时间点的不同切片。1998年是代码被写的那个切片，2024年是他被投放到系统里的那个切片，2147年是他发现真相的那个切片。

他现在在2147年，在游乐园里，在系统原型代码面前。

闭环的本质是时间循环。他的生命，从出生到进入系统到"未来"，是一个无限循环。他一遍一遍经历同样的时间线，一遍一遍写同样的代码，一遍一遍寄同样的邮件。然后系统清除他的记忆，让他从头开始。像一个存档系统：每次循环开始时加载一个干净的存档，把他放回起点。

但有些东西系统清除不掉。那些太深刻的记忆，那些被刻进代码里的记忆，那些藏在照片墙和保险箱里的记忆。

他的手在抖。指尖发麻，腕关节的骨头在轻微震颤。是认知冲击之后的生理反应，不是恐惧。像是大脑在重新布线，旧认知被抽走，新的认知还没接好。

他是系统的主人。是这个无限世界的创造者。他在2147年创造了系统，然后在1998年，同一个闭环的不同切片，进入系统，然后在系统里遗忘了自己是谁，然后在2147年，同一个闭环的另一个切片，回到系统，重新发现自己是谁。

像一个程序员写了一个游戏，然后忘记自己写过这个游戏，然后在游戏里玩，然后在游戏的某个角落里发现自己写的代码。

他醒来。屏幕上那行注释还在。

> # 备注：这是一个实验性的闭环系统。目标：测试意识在循环中的稳定性。

他写的。他写的这行注释。每个标点符号都是他的手敲上去的。

测试意识在循环中的稳定性。

这个系统是一个实验，不是游戏，不是筛选器，也不是未来文明的工具。他在测试意识在无限循环中的稳定性：看一个意识能不能一遍一遍循环中保持自我，能不能一遍一遍遗忘中找回自己。

他在做实验。而他自己是实验对象。

就在这时，一个声音在他脑海中响起。

冷，不带任何情感，全新的，像金属碰到金属，不是系统的广播，不是沈知秋的声音，也不是任何他之前听过的声音。

> 「检测到玩家叶文轩接触了受限制信息。」
> 「检测到玩家意识活跃度超过安全阈值（当前：+340%。）」
> 「启动记忆校正程序。」
> 「3……2……1……」

叶文轩的心脏猛跳了一下。跳得太猛，肋骨内侧震了一下。

记忆校正程序。

系统在删除他的记忆。全部，不是30%。关于系统原型的、关于2147年的、关于闭环的、关于邮件的一切。系统要把他变回一个普通的等级1洞察者，一个只知道"结构透视"、不知道系统真相的玩家。

"不！"他的手伸向键盘。

想保存邮件。想把邮件内容拷贝到系统面板的文本编辑器里，系统面板是私有空间，校正程序触及不到。也许能保住一部分。

但他的手指没有碰到键盘。

屏幕上的代码编辑器在闪烁。代码一行一行地消失，像文件在被快速删除，字符从屏幕上飞出去，被某种看不见的力量吸走。系统核心代码。文件名变成了"未命名"。注释消失了。变量名消失了。逻辑结构消失了。邮件的最后一行是最后一个消失的。

——来自2147年的叶文
然后屏幕黑了。

老式CRT显示器闪了一下，变成一片空白。电脑关机了。散热风扇的嗡鸣停了，房间里只剩下低音喇叭从远处传来的呻吟声，隔了几道墙，已经模糊不清。

叶文轩的手还悬在键盘上方。

脑子里的记忆在迅速消退。代码在消失，邮件内容在消失，2147年在消失，闭环在消失。像墨水被清水冲开，他看见文字在稀释、淡去。他用尽全力抓住了一样东西。

那枚绿色软盘。从保险箱拿出来的时候就已经放进了口袋。软盘在口袋里，校正程序触及不到口袋里的东西。

软盘是物理的。校正程序只能删除系统内的记忆。物理世界的物体，它触及不到。

脑子在飞速变白。代码、邮件、2147年、闭环，一样一样在消失。每一秒都比上一秒空白更多，像有人在水池底部拔掉了塞子，记忆顺着看不见的洞口往下沉。

但在空白之中，有一个东西他没有忘记。
0428。

4月28日。系统启动的日子。

这个数字刻在脑子里，他自己的记忆，不是系统记忆。是他在某个循环中深深记住了的数字，刻得足够深，深到校正程序擦不掉。像刻在骨头上的纹路，肌肉萎缩了，骨头还在。

校正程序清除不掉0428。

因为0428是他自己给自己的记忆，不是系统给他的。

叶文轩睁开了眼睛。

他站在鬼屋的镜子前。镜子里的他看起来很困惑，像是刚睡醒，脑子里一片空白，瞳孔在适应光线。

但口袋里的软盘还在。棱角硌着大腿：真实的触感，硬塑料的边缘隔着裤子顶在皮肤上。他悄悄把软盘往口袋里按了按。

他看了一眼赵大嘴。赵大嘴也看起来很困惑。眼珠转了两下，像刚从一场深梦里被叫醒。瞳孔放大又收缩，在适应环境。

"我们，"赵大嘴的声音很轻，"我们在哪里？"

"鬼屋。"叶文轩说。声音比他自己想象的平稳，像程序输出了一条没有异常的日志。"我们在找硬币。第三枚。"

赵大嘴愣了一下，揉了揉眼睛。手指在太阳穴上按了两秒。

"对。"他说。像是在确认，又像是在说服自己。"硬币。第三枚。"

他看着叶文轩。眼神里有某种东西在闪，像是有什么在试图浮现，但被什么力量压了回去。眼皮跳了一下，左眼，跳得很快，连跳了三下。

"我刚才，"他的声音卡顿了，半秒的停顿，像信号接触不良，嘴唇动了一下没发出声音，然后又重新开口。"我好像做了一个梦。"

"什么梦？"

赵大嘴摇了摇头。揉眼睛的手指放下来，按在太阳穴上。"记不起来了。但梦里有一个声音。在跟我说一些话。关于，关于螺旋的。"

叶文轩看着他。

赵大嘴的封印也在松动。校正程序影响了赵大嘴的记忆，但赵大嘴的封印比叶文轩的记忆更坚固。系统清不掉赵大嘴的深层记忆，那些被封印在螺旋核心里的记忆。

赵大嘴记得一些东西。只是他说不出来。像喉咙里卡了一个词，使劲咽也咽不下去，卡在食道最窄的那个位置。

"走吧。"叶文轩说。"硬币在镜子后面。"

他们推开大镜子。铰链没出声。后面有一个暗格，暗格里有一枚铜色的硬币，表面刻着螺旋花纹。硬币拿在手里有分量，金属的凉意传到指腹。

游乐园硬币，三枚了。

叶文轩把第三枚放进口袋。硬币碰了碰软盘，硬碰硬，发出极轻的一声脆响。

出口需要六枚。还差三枚：过山车、海盗船、碰碰车场。

但他们现在有更重要的事。

他的手按在口袋里的绿色软盘上。棱角硌着掌心：真实的。软盘里有一封邮件。他写的。来自2147年。

系统清掉了他的记忆。但没有清掉软盘。没有清掉0428。

没有清掉他脑子里的某个东西，那个东西在系统的校正程序下幸存了。像一颗种子埋在灰里，火熄了，根还在。他不知道那是什么，但他感觉得到它的存在，像脚底下有微弱的震动，频率很低，几乎感觉不到。

他跟着赵大嘴往鬼屋出口走。

脚步很稳。表情很平静。透视在运转：看穿墙壁，看穿迷宫，看穿整个游乐园的结构。

但脑子里有一个空白。系统清除不掉的空白。空白里藏着真相。

他会在某个时刻找回那个空白。不是现在。现在不是时候。

而现在，他要继续走。继续通关。继续升级。继续拆解这个系统。

手按在口袋上。软盘贴着大腿。0428在脑子里。

足够了。
