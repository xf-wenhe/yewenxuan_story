# 第一百零七章：规则不同

断崖下面不是悬崖。是路。

韩冰走在前面，脚踩在一块凸起的岩石上，岩石下面是一道看不见的阶梯，一步步嵌在崖壁上，窄得只能放下一只脚。阶梯的每一级都刻着细小的纹路，像是有人特意磨上去的防滑线。

叶文轩数了数。阶梯一共七十三级。他从上面往下数，七十三。韩冰从下面往上数，也是七十三。两个人数的台阶数是一样的。

"这条路的台阶数是固定的。"叶文轩的声音，"不会因为上下方向改变。"

"区域B的副本里有类似的。"韩冰的声音没有回头，"但那是在副本里。区域C的路，走到哪里都是固定的。这里的一切都是写死的。"

叶文轩皱了一下眉。写死，用程序员的说法，就是硬编码。变量被锁死，参数不可变。区域C的所有规则，都是硬编码的，没有弹性，系统不留任何自动生成的空间。

三个人沿着阶梯往下走。韩冰走在前面，赵大嘴走在中间，叶文轩走在最后。阶梯越来越窄，到后来两侧的崖壁几乎贴在一起，只能容一个人侧身通过。赵大嘴走在中间，好几次肩膀被石壁蹭到，嘴里嘟囔了几句。

"这路比区域B那个狭窄副本还窄。"赵大嘴的声音，被石壁弹回来，闷闷的。

"区域B的副本至少会宽一点让你喘气。"叶文轩的声音，"这里不给你喘气的机会。"

赵大嘴咽了口唾沫，不再说话。他把背包往胸前拢了拢，侧着身子一步一步往下挪。他的金色眼睛在暗处闪得很慢，像是在极力压缩自己的存在感，怕一个不小心碰着了什么机关。

走到第七十三级，阶梯到头了。脚下是一片平地，平地的尽头是一扇门，门的样式和区域B的公共传送门很像，蓝白色的光从门缝里渗出来，门上浮着一行字：

「区域C·边境市场。玩家等级上限：Lv.100。死亡掉落：全部。玩家互杀：无惩罚。」

叶文轩把那一行字看进眼里。死亡掉落：全部。玩家互杀：无惩罚。这两行字比区域B的规则狠得多。在区域B，玩家死亡会掉部分装备，系统会惩罚主动攻击其他玩家的行为。区域C里，死了就一无所有，杀了人也不会有人管。

"区域C的规则。"韩冰的声音，"比你想的狠。"

叶文轩没有回答。他站在那扇门前，先用结构透视扫了一遍门的底层结构。门的结构比他想得简单，它只是一道单向的边界，没有机关，通的就是边境集市。可扫到边界那一层的时候，叶文轩停住了。

门的边界上，浮着一层几乎看不见的代码。不是系统生成的那种规整的代码行，是手写的，潦草，排列不规则，像有人在上面随手涂了几行字。叶文轩把结构透视的层次往下压了一层，凑近看那些字。

那些字写的是一种注释语言。叶文轩认得。是他自己的注释习惯：用斜杠开头，后面跟一行中文，偶尔夹几个英文术语。那些字的内容，他读得懂，但读懂了之后，他的后背出了一层冷汗。

「if (player_id == ye_wenxuan) { enable backdoor_A; enable backdoor_B; // 从下往上数第七十三级台阶下面的裂缝里，藏着一把裂隙钥匙。不要让系统知道。}」

叶文轩把视线从那段代码上移开。他抬起头，看向阶梯侧面那片崖壁。崖壁上确实有一道极细的裂缝，不仔细看根本看不见，缝里渗着蓝莹莹的光。

二十七岁的自己，在区域C的边界代码里，给他留了一个后门。一把裂隙钥匙，藏在第七十三级台阶下面的裂缝里。不让系统知道。

"韩冰。"叶文轩的声音。

"嗯。"

"这里有个后门。是系统不知道的后门。"

韩冰看了他一眼，然后顺着他的目光看向那道裂缝。她的眉梢动了一下。

"你确定？"

"确定。"叶文轩的声音，"代码落款是我二十七岁的笔迹。只有我自己能写出那样的注释。"

韩冰没有再问。她从腰上解下一根细绳，扔给叶文轩。绳子的末端是一枚钩子，钩子很小，刚好能塞进那道裂缝。

"把钥匙取出来。"韩冰的声音，"然后我们进集市。"

叶文轩把钩子伸进裂缝，勾了两下。钩子勾住了一个硬邦邦的东西，他往外一拉，拉出来一枚指甲盖大小的金属片，形状像一把钥匙，表面刻着螺旋的纹路。

他把钥匙收好，跟着韩冰穿过那扇门。

门后面是集市。他们从市场北边的入口进来，一进去就融入了人群。叶文轩低着头，帽子压得很低，赵大嘴跟在他身后，金色的眼睛藏在阴影里。

集市里比叶文轩想象的大得多。地面是拼合的岩石，踩上去有轻微的弹性，不像普通的石板路那么硬。头顶是缝合的天空，一半是白昼一半是黑夜，交界处的光斜斜地切下来，把整个集市切成明暗两半。光落在脸上的时候是暖的，走到暗处的时候又冷得刺骨。

"集市里现在不能待太久。"韩冰的声音，"你的名字被悬赏了，集市里有很多双眼睛盯着新来的S级。我们找一个安全的地方，把你知道的都告诉我。"

"我知道的。"叶文轩的声音，"区域C的规则代码里，有我二十七岁留的后门。归位之门需要锚点和核心节点同时进去。我女儿的名字不在'叶朵朵'。孙鹏的人在找我。"

韩冰点了点头。"觉醒者有一个据点，在集市的西边，一间地窖里。我带你去。路上不要看任何人的眼睛，不要和任何人搭话。集市里有孙鹏的人。"

三个人往集市西边走。叶文轩低着头，目光落在脚下的地面上。脚下的石板拼接处有一条一条细缝，缝里渗着蓝光，像41枚0428碎片拼起来的底图。他跟着韩冰走，没有东张西望。

可即便这样，他还是感觉到有几道目光落在他们身上。不是敌意，至少不只是敌意。那些目光里有好奇，有打量，有一些他读不懂的东西。像在看一件不该出现在这里的东西。

"有人在看我们。"赵大嘴的声音，压得极低。

"不要回头。"韩冰的声音。

三个人继续走。赵大嘴没有回头，只是把金色眼睛的频率压得更低，像在把概率感知往回收。他的眉头皱得很紧，像是在忍受什么。

"概率感知太吵了。"赵大嘴的声音，更低了，"集市里几百号人，每个人的概率都在往我脑子里灌。太多太多了。"

"再忍一下。"叶文轩的声音，"到了地窖就安静了。"

赵大嘴嗯了一声，嘴唇抿成了一条线。他跟着叶文轩和韩冰，一步一步走进集市西边那片更暗的地方。路两边的石屋越来越高，头顶的天空被石屋遮住了，暗处的蓝光从石板缝里渗出来，照在三个人的脚下。

走了大约十分钟，韩冰在一堵石墙前面停下来。墙上没有任何标记，就是一堵普普通通的石墙，上面长着一些苔藓。韩冰把手放在墙上，按了三个位置：左上方，正中间，右下方。每按一下，墙里传来一声极轻的咔嗒声。

石墙往旁边滑开了，露出一道向下的石阶。

"进去。"韩冰的声音，"说话小一点。地窖里有觉醒者。"

三个人走进去。石阶很窄，只能容一个人通过，两侧的墙壁是土坯的，摸上去是凉的。走了大约二十级，石阶到头了，前面是一扇铁门。韩冰敲了三下，门从里面打开，一个穿灰衣服的女人探出头来，看了一眼韩冰，又看了一眼叶文轩和赵大嘴，没有说话，侧身让开。

地窖比想象的大。有灯，有桌子，有十几把椅子，墙角堆着武器和道具。七八个人坐在不同的角落里，有的在整理装备，有的在翻看碎片，看见韩冰进来，都抬了抬头，然后又低下头去。

"这些人都是觉醒者。"韩冰的声音，"边境小队。跟我一起来区域C的。你可以信任他们。"

叶文轩的目光扫过那些人的脸。每个人的表情都很平静，平静得不太像活人。他们看到叶文轩的时候，没有好奇，像是早就知道他一定会来。

地窖里有一张长桌，桌上铺着一块布，布上画着裂隙的简图。韩冰走过去，把手指按在图上的一个红点上。

"这里。"韩冰的声音，"边境集市的出入口。红色的是0429势力的巡逻路线。蓝色的是觉醒者的安全路线。"

叶文轩凑过去看。简图上的红点密密麻麻地分布在集市的三条主路上，蓝线绕开红点，形成三条隐蔽的通道。

"孙鹏的人布得很密。"叶文轩的声音。

"他们有三股势力。"韩冰的声音，"一股在集市南边守着副本入口，一股在北边守着通往外界的路，还有一股在集市中央的公告牌附近活动。你在集市里待的时间越长，越容易被三股势力的人同时发现。"

"他们为什么这么拼。"叶文轩的声音，"悬赏不过五十枚时空结晶。"

韩冰看了他一眼。"不是为结晶。"韩冰的声音，"0429势力在收集0428碎片。他们知道集齐42片能打开归位之门。他们要先你一步拿到碎片，抢先打开门。"

叶文轩的眉心拧了一下。孙鹏也在找归位之门。而且孙鹏的势力已经渗透到了区域C的边境，情报网比他想象的更密。

"他们现在有多少片。"叶文轩的声音。

"不知道。"韩冰的声音，"但觉醒者的人在集市外围捡到过0428碎片的残片，编号在0380到0400之间。他们至少已经拿到了二十片以上。"

二十片。叶文轩背包里有41片。孙鹏的人如果集齐了41片，会比他更快到达归位之门。时间不多了。

"你们的碎片呢。"叶文轩的声音。

韩冰沉默了两秒。她从腰上的一个布袋里倒出几枚碎片，放在桌上。五枚。编号分别是0330、0342、0355、0367、0378。

"边境小队一共找到了五片。"韩冰的声音，"觉醒者总部手里有多少，我不知道。总部在裂隙的更深层，信息传不过来。"

五片。加上叶文轩的41片，一共46片。孙鹏的人至少有20片。觉醒者总部可能还有更多。三方都在抢归位之门的钥匙。

"你帮我拆副本规则。"韩冰的声音，"我帮你抢在孙鹏前面到达归位之门。各取所需。"

叶文轩点了一下头。他把简图上的蓝线记在心里，三条安全通道的走向，从集市的哪一个入口进，从哪一个出口出，每一段的距离有多远。

"明天一早出发。"韩冰的声音，"走北边的安全路线，绕开0429的主力。我安排两个人跟你们走到中点。"

"中点之后呢。"叶文轩的声音。

"中点之后的路，觉醒者走不了。"韩冰的声音，"时间封印在中点一带太浓了，觉醒者的能力会被压制。你们只能靠自己。"

叶文轩嗯了一声。他看向赵大嘴。赵大嘴坐在角落的一张椅子上，金色眼睛在暗光里闪得很慢，像是在极力降低自己的存在感。

"大嘴。"叶文轩的声音。

赵大嘴抬起头。"嗯。"

"你的概率感知怎么样。"

"还行。"赵大嘴的声音，"地窖里人少了，不吵了。"

叶文轩没有再问。他走到角落，找了一个相对干净的地方坐下来，背靠着墙。赵大嘴跟过来，在他旁边坐下来。

两个人沉默着。地窖里的灯暗了下来，有人在关灯。脚步声在远处，声音很低。然后一切都安静了。

他想起自己在区域C边界代码里看到的那行注释。27岁的自己，在系统里留了一个后门。一把裂隙钥匙。一个指向螺旋终端的路径。

27岁的自己知道的事情，比现在的他多。叶文轩闭上眼睛。明天一早出发。

（第一百零七章完）
