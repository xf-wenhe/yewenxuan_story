# 第四百零二章：空白画布

地面是半透明的，踩上去没有实感，像踩在一层结冰的玻璃上。叶文轩低头看着鞋底，代码层在脚下流淌，蓝色的细线逆着他的步伐方向跑，像溪水绕过石头。他能看见地面之下的结构——不是区域C那种固定的、写死的代码，这些代码在动，在变化，像是有呼吸一样。

0429碎片在赵磊的脑子里说话，声音比平时清晰，不再卡顿。"这里不是区域C。"

"是哪里？"叶文轩在意识里问。

"是我的内部。一个空白的画布。"

叶文轩放慢了脚步。这个空间没有边界感，海面在他左侧延伸出去，灰蓝色的天和水接在一起，分不清哪边是海哪边是天。阳光从上方照下来，温度是温的，不像区域C那种系统生成的冷光。

0429碎片的蓝绿色光从赵磊胸口透出来，透过T恤布料在空气中散开一圈淡光。"没有副本。没有怪物。没有规则。只有可以被编写的东西。像一个干净的硬盘，没有被格式化过。"

叶文轩的心跳快了一拍。他以前在系统里面见过代码——在区域C的深处，在他的结构透视视野里。那些代码是静态的，是写好的，是不能改的，像刻在石头上。但眼前这些代码不一样。它们在流，在变，在生长。他低头看了一会儿，脚边的几行代码正在重组，蓝色的线交织成一段他没见过的逻辑结构，然后又散开，像水面上被风吹散的油膜。

"虚拟机。"0429碎片在赵磊脑子里说，"一个干净的运行环境。没有旧系统的残留，没有闭环的规则，没有筛选的机制。赵磊的身体是硬件，我是操作系统。你是程序员。"

叶文轩抬头看了赵磊一眼。赵磊正站在海风里，胸口的蓝绿色光随着0429碎片的声音在轻微脉动，像一个指示灯。

三个部分——硬件、操作系统、程序员——他们三个在一起，搭建一个系统。

"那陈小鱼呢？"叶文轩问。

0429碎片亮了一下，频率变了。"0428碎片是沈知秋的意识。她是系统的情感引擎。陈小鱼的身体是0428碎片的容器。她会是新系统的情感核心。"

叶文轩转过头。陈小鱼蹲在不远处的地面上，专心玩着沙子，用小铲子往塑料桶里铲，铲一下抬头看他一眼，然后又低下头继续铲。0428碎片在她胸口发着淡蓝色的光，透过碎花裙子的布料在皮肤表面散开一圈微光。她的注意力完全在沙子上，好像没感觉到自己身体里多了一个意识。

沈知秋的意识在她的身体里面，安静地注视着。叶文轩感到0428碎片的存在——不同于0429那种直接的语言。它是一种温热的、安静的脉动，像一个母亲坐在旁边看着女儿玩。

四个部分——硬件、操作系统、情感核心、程序员——他们四个在一起，搭建一个全新的系统。

叶文轩没有立刻行动。他沿着半透明的海岸线走了一段，脚下的代码层跟着他的脚步在轻微波动。空间在缓慢变化，海面的颜色时深时浅，代码瀑布在远处的天边挂着一道淡蓝色的帘幕，水流往下落，没有声音，像一幅静止的画。

赵磊跟在他身后，没说话，但叶文轩感到他的存在——不是碎片的信号，是赵磊本人的注意力，稳稳地落在他的背上。陈小鱼后来也站起来跟着走，小桶和铲子挂在胳膊上，碎花裙子上沾了沙子，0428碎片的光随着她的步伐在胸口一跳一跳的。

走了很久——也许是真的很久，这个空间里没有太阳，没有时钟，没有系统广播的时间戳，时间失去了刻度，叶文轩靠呼吸计数来估算，数到第五百七十二次呼吸的时候，他看见地面上的代码层里嵌了一行字，停下了脚步。

那行代码很小，嵌在半透明表面的表层结构里，淡蓝色的字体，像有人用手指在水面上写的一行字。

`如果 (玩家 == 叶文轩): 返回 真`

叶文轩盯着看了三秒。心脏在肋骨后面跳了一下，很轻的一下，像有什么东西从记忆深处浮上来又沉下去。

他以前见过这行代码。在旧系统的碎片里，在被击败的系统碎片的底层代码中，他都见过相同的结构。但这里不是旧系统。这里是0429碎片的内部，是一个空白的画布，一个干净的运行环境。为什么会有这行旧系统的代码？

"0429。"叶文轩在意识里叫它。

0429碎片振动了一下，频率降低。"我不知道。这行代码不是我写的。它在我里面——从我有意识开始就有了。"

叶文轩蹲下来，手指碰了碰那行代码。代码闪了一下，蓝色的光顺着他的指尖往手臂上爬了一小段，然后散开了，像被风吹散的烟雾。

这不是0429写的。那这是谁写的？

0429是旧系统的产物。它的意识是旧系统给的。这行代码在它意识的最底层，从它有意识开始就存在。那么只有一种可能——这行代码是旧系统写进0429的初始代码的一部分，是旧系统在0429被创建的时候就埋进去的一个后门，一个针对叶文轩的后门。

"0429。"叶文轩的声音在意识里很稳，"你意识的最深处有旧系统残留的代码。就刚才那行。"

0429碎片振动频率加快了。"残留代码？我不明白——"

"就是那行。`如果 (玩家 == 叶文轩): 返回 真`。在你的最底层，从你有意识开始就在那里了。"

0429碎片沉默了一会儿。叶文轩感到它在向内搜索，像一个人在黑暗的房间里翻找一件东西。"我找到了。在我从未注意过的一个地方。它像是我的一部分……但我不知道它是什么。"

叶文轩站起来。他以前以为旧系统只是一个整体——一个庞大、封闭、不可改变的东西，像一座山。但现在他清楚，系统是可以被拆分的。0429碎片是翻译器，0428碎片是情感引擎，赵磊是锚点，他是程序员。系统不是一个山，是一堆积木，可以拆，可以重装。

旧系统在0429的底层留了一个触发器。一个只在叶文轩出现时才会激活的触发器。

为什么？

叶文轩抬起手，手指在空中划动。0429碎片立刻开始翻译他的意识，把他想到的查询语句转换成系统语言，淡蓝色的代码流从他的指尖涌出来，在半空中展开成一面悬浮的屏幕。0429把自己的内部代码展示给他看。

代码堆得很密，逻辑嵌套了很多层，但叶文轩读代码的速度比读中文还快——毕竟写了十几年。他从最底层开始往下翻，一层一层剥，像剥一棵树的年轮。

然后他看到了一个函数定义。名字是`处理_玩家_叶文轩`。

叶文轩的心跳停了一拍。这是一个专门为他写的函数，在0429碎片的意识最深处，从0429碎片有意识开始就存在。

函数的内容只有三行：

```中文
定义 处理_玩家_叶文轩():
    如果 (碎片_0429.激活 和 玩家 == 叶文轩):
        返回 真  # 锚点A已激活。准备就绪。
    否则:
        返回 假
```

叶文轩的目光落在注释上。`锚点A已激活。准备就绪。`

中文注释。旧系统的代码全部用拼音，不会用中文写注释。写这行注释的人，习惯用中文。

叶文轩的胸口在跳，跳得很快。父亲建了系统，父亲和日本人一起建了系统，父亲在系统里留了很多东西——记忆碎片、声音、话、碎片编号。现在又多了一行代码。父亲在0429碎片的意识最深处，给叶文轩留了一个标记，一个专门为他准备的标记。

父亲。父亲知道叶文轩会来，知道他会激活0429碎片，知道他会建一个新的系统，父亲在0429碎片的里面留了一个标记等着叶文轩来看。

"0429。"叶文轩的声音在意识里很轻，"这行代码周围还有什么。全部给我。"

0429碎片振动频率加快，在自己的意识里搜索。更多的代码从虚空中浮现，蓝色的光在发亮，一行一行地排列出来，像水面上浮出的一串气泡。

叶文轩看到更多函数。每个函数都有中文注释。都是父亲写的。

```中文
定义 处理_玩家_赵磊():
    如果 (碎片_0429.已激活 和 玩家 == 赵磊):
        返回 真  # 锚点B已激活。准备就绪。

定义 处理_碎片_0412():
    # 0412碎片持有者：冰。位置：俄罗斯塔。状态：沉睡。
    # 唤醒条件：锚点A和锚点B的共同信号。

定义 处理_碎片_0415():
    # 0415碎片持有者：守。位置：日本塔。状态：沉睡。
    # 唤醒条件：锚点A和锚点B的共同信号。

定义 处理_碎片_0427():
    # 0427碎片持有者：李明。位置：韩国塔。状态：沉睡。
    # 唤醒条件：锚点A和锚点B的共同信号。

定义 处理_碎片_0428():
    # 0428碎片持有者：沈知秋（陈小鱼）。位置：中国塔。状态：已激活。
    # 情感引擎。桥梁系统的核心。
```

五个函数。五个碎片。五个人。每个函数都有父亲的中文注释，每个函数末尾都标记着"准备就绪"。

父亲在0429碎片的意识最深处留了一整套代码。一整套针对五个碎片、五个人的代码。父亲知道叶文轩会来，知道他会激活这些函数，知道他会建一个新的系统。父亲把一切都准备好了。

赵磊站在叶文轩旁边，看着虚空中的代码在发亮。他看不懂代码，但那层蓝绿色的光照在他脸上，他的表情是安静的。

"小叶。"赵磊在自己的意识里说，声音很轻，"你找到什么了？"

叶文轩没有立刻回答。他看着那些函数定义，一行一行地读，父亲的中文注释在蓝色的光里安静地躺着。"我找到父亲留的东西了。"他最后说，声音里有一层他自己也没注意到的温度，"他在0429的最深处留了一整套代码，等着我来。"

赵磊的胸口在跳。0429碎片的声音在他的意识里响起来，比平时更软："你父亲很了不起。他在很久以前就知道你会来。"

叶文轩点了下头。他以前以为父亲只是一个受害者——旧系统的牺牲品，被系统控制的一个人，失去了记忆，变成了碎片里的回声。但现在他清楚了，父亲不是受害者。父亲是系统的建造者之一，父亲在系统里留了很多东西，等着叶文轩来发现，等着他来建一个新的系统。

"0429。"叶文轩在意识里问，"你能激活这些函数吗？"

0429碎片的振动频率降了下来。"我不知道。这些函数需要锚点A和锚点B的共同信号。我现在只有锚点A的信号。锚点B的信号——"

它停住了。叶文轩转头看赵磊。赵磊也看着他，两个人对视了一秒，赵磊的表情从疑惑变成一种缓慢的明白。

"我？"赵磊在自己意识里问。

"是的。"0429碎片的声音响起来，"你就是锚点B。你的概率扭曲能力就是锚点B的力量。"

赵磊的胸口上的蓝绿色光变强了。他低头看了一眼自己的胸口，像是想透过T恤布料看到里面的碎片。他以前以为自己的运气只是运气——系统给的，随机的，莫名其妙的。现在他清楚了，那不是运气。那是能力。概率扭曲。锚点B。

"那怎么激活？"赵磊问。

叶文轩低头看代码。函数的触发条件很简单：碎片0429已激活，玩家等于赵磊。0429碎片已经在赵磊的身体里，已经激活。赵磊是玩家。赵磊等于赵磊。条件已经全部满足了。

"0429。"叶文轩的声音很稳，"触发条件已经满足。激活函数。"

0429碎片振动起来，频率在加速。蓝绿色的光从赵磊胸口涌出来，透过T恤布料向四周扩散，一层一层地往外扩，照亮了半透明的地面，照亮了远处的代码瀑布，照亮了陈小鱼蹲在那边玩沙子的背影。

赵磊闭上眼睛。海风吹过他的脸，他的眉头皱起来，手攥成了拳头，按在自己胸口上面。叶文轩感到0429碎片在赵磊的身体里震动，震动很强，从赵磊身上传到地面，再从地面传到叶文轩的脚底，整片空间都在轻微发颤。

代码瀑布在上方闪烁，蓝色的光在流动。地面上的代码层在跑，速度快得看不清线条。然后一切停了。代码瀑布停了。地面上的代码停了。虚空中的代码屏幕熄灭了。0429碎片的振动消失了。赵磊胸口上的光暗了下去。

叶文轩的意识里响起一个声音，很远，很轻，像从很远的地方传过来——

「锚点B已激活。准备就绪。」

赵磊睁开眼睛。海风吹着他的头发，蓝色的光在他眼底映出一片淡蓝。他的手从胸口放下来，低头看了看自己的手掌，然后又抬头看叶文轩。

"感觉到了。"赵磊对自己说，声音里有一种压不住的、细微的震动，"脑子里有东西在亮。很暖的。像是……我丢了好久的东西，找回来了。"

叶文轩点了下头。赵磊的概率扭曲能力已经完全激活了。锚点B已经就绪。五个函数中的第一个已经启动。

虚空中的光闪了一下。一行新的文字在蓝色背景中浮现：

> **「锚点共识检测：开启。当前共识值：23%。请继续建立共识。」**

叶文轩看着那行字。23%。只有23%。还有四个碎片的持有者要唤醒，还有很长的路要走。但锚点A和锚点B已经同时激活了。他们从23%开始。

他转头看赵磊，又看蹲在不远处玩沙子的陈小鱼，然后看向远方的代码瀑布。

"我们继续。"叶文轩说，声音很稳，"先完成桥梁的基础结构，然后去唤醒他们。"

赵磊点了下头，两个人站在虚空前面，蓝色的光从上方照下来，代码瀑布在他们头顶流淌，像一道倒着落的水。陈小鱼跑了过来，小桶和铲子挂在胳膊上，碎花裙子上沾满了沙子，0428碎片在她胸口发着淡蓝色的光。

"叔叔你们在看什么？"陈小鱼的声音。声音飘在空气里，很轻，带着好奇。

叶文轩低下头看着她，又看向她胸口那团淡蓝色的光。沈知秋的意识在那个身体里，安静地微笑着。

"在看未来。"叶文轩说，声音里有一层他自己也没察觉到的轻。

陈小鱼歪了歪头，不太懂。但她没追问，只是拉住了叶文轩的衣角，手指很小，攥得很紧。

叶文轩抬起手，手指在虚空中划动。0429碎片立刻开始翻译，0428碎片跟着亮起来，两个碎片的光交织在一起，像两束不同颜色的光穿过同一块棱镜。代码从叶文轩的指尖涌出来，一行一行地在虚空中堆积，蓝色的光在发亮，像有人用光在搭一座桥的骨架。

陈小鱼看着那些代码在发光，眼睛睁大了些。她不懂代码，但她觉得好看。蓝色的光一闪一闪的，像星星，像萤火虫。

"叔叔这是什么？"陈小鱼问。

叶文轩的手指没有停，意识在流，代码在涌。"一个新的世界。"他想。然后他补了一句，声音很轻，只给自己听见，"爸爸在给你建一个新的世界。"

陈小鱼的眼睛亮了一下。她从不知道代码是什么，以前以为代码是叶叔叔的东西，是难的东西。现在叶叔叔说代码是一个世界。是一个给她的世界。

赵磊站在旁边，没说话，但叶文轩感到他的注意力稳稳地落在这里。0429碎片在赵磊胸口亮着，蓝绿色的光在往外扩散，0429碎片的声音在赵磊的意识里安静地响着。

"我帮你守着。"赵磊对自己说，很轻，很认真，"你写。我看着。"

叶文轩的手指在空中停了一下，很短的一瞬，然后继续往下写。代码在虚空中堆积，一行一行，一层一层，像一座用光砌的山在往上长。0429碎片在翻译他的每一个想法，0428碎片在共鸣，两个碎片的光在他的指尖同步脉动。

远处的代码瀑布还在流，蓝色的光从上方照下来，照着三个站着的人。

（第四百零二章完）
