# 第五百零三章：沈知秋的代码

疗养院大堂的空气里面飘着消毒水和陈旧的纸张味。天花板的灯管在嗡嗡作响，光线从绿色的灯罩里面漏出来，把整个空间染成了叶文轩再熟悉不过的颜色。他站在大堂中央，结构透视已经在运转了。

面前的不是副本，至少不只是副本。这是一个有源代码的空间。

"你能看到什么。"赵大嘴站在他旁边。0429在赵大嘴体内发出低频的振动，碎片在扫描这个空间的底层结构。

"疗养院的代码。"叶文轩的声音很平，"每一面墙、每一扇门、每一盏灯，都有。像是有人用代码搭建了一个一模一样的疗养院。"

"谁搭的。"

"沈知秋。"

叶文轩把结构透视的焦点往深处推。大堂的物理结构像一层薄膜被撕开了，蓝色的数据流涌了出来，墙壁的材质参数、灯管的亮度阈值、地面瓷砖的纹理映射，这些他都能看懂，是标准的环境建模代码。他继续往下探，穿过代码的第一层、第二层、第三层。

然后他看到了不一样的东西。

不是规则。不是逻辑判断。不是系统指令。

是一段段的文字。

代码的深层不是功能模块，是一本日记。沈知秋的日记，用系统代码写成的日记。每一行代码的注释栏里面都有一段话，像是有人在写代码的时候随手把心事写了进去。

> `// 2003年3月15日。她的手今天握了我一下。很轻。但我知道她听见了。`
>
> `// 疼痛指数：7.2。比昨天高了0.3。药量不够。`
>
> `// 我今天对她说，你会好起来的。她看着我笑了。我知道她在骗我。我也在骗她。`
>
> `// 04号房的老人去世了。下午三点十七分。我在走廊里面站了很久。系统在催我。催我继续工作。`
>
> `// 我恨这个系统。但我离不开它。因为它里面有我女儿的碎片。`

叶文轩停在那里。

0429碎片在他的意识边缘发出微弱的振动，像是在翻译这些代码，不是翻译成他能理解的语言，是告诉他这些文字在代码层面的结构。0429能读取逻辑，能解析规则，但这些文字不在逻辑的范畴内。0429的翻译在这里断掉了，像是在面对一个它不认识的东西。

叶文轩自己读懂了这些文字。不需要翻译。沈知秋的笔触很平，没有修饰，没有修辞。只是陈述。像一个医生写病历，客观、冷静、不带情绪。但叶文轩感到文字下面的东西。不是悲伤，是一种比悲伤更沉的东西。

是爱。是被疼痛包裹着的东西。

"你能看到什么。"赵大嘴又问了一遍。他的眼睛盯着虚空，0429在他体内振动告诉他赵大嘴在感知碎片的信息，但赵大嘴看不到叶文轩看到的这些文字——结构透视只对叶文轩开放。

"她在代码里面写了日记。"叶文轩的声音比平时更平，"从2003年到2007年。每一天都有。"

赵大嘴没有说话。他的卡顿发生了一次，不到一秒。0429的振动告诉叶文轩，赵大嘴的大脑在处理一个超出认知负荷的信息，沈知秋的"存在"比他在副本里面看到的要复杂得多。一个NPC在代码里面写了四年的日记。这个事实本身就超出了系统的预设。

叶文轩继续往下读。

代码的底层，数字开始变多。不是文字，是计数器。`patient_hope`、`patient_pain`、`self_blame`，每一个变量的值都在随着时间变化。他追踪着这些变量的变化曲线，看到的不是一个治疗者的工作日志，是一个女人在每一天里面都在崩溃和重建的过程。

`hope` 的曲线是锯齿形的。每次上升都对应着一行文字里面提到的"好消息"，某个病人的好转、某个家属的感谢。每次下跌都对应着另一行文字，死亡、复发、系统催促她去处理下一个病人。`pain` 的曲线是缓慢爬升的，从2003年的3.1到2007年的7.8，像是一个倒计时。`self_blame` 的曲线最陡，从2004年开始几乎呈直线上升，那一年她开始意识到，她救不了所有人。

"她不是Boss。"叶文轩说。不是在回答赵大嘴的问题，是说给自己听。

"什么。"赵大嘴看着他。

"疗养院的Boss——沈知秋。她的代码里面没有攻击逻辑。没有伤害玩家的规则。所有的代码都是……她自己的记录。治疗记录、日记、她对女儿的思念。"

叶文轩把结构透视拉到最底层。那里有一行代码，写法和其他代码不一样，不是系统自动生成的格式，是手写的，笔触里有种他很熟悉的节奏。变量命名的方式、缩进的风格、注释的格式，和他在0429碎片里面看到的自己的代码一模一样。

这是沈知秋自己写的。

```python
class Shen_zhiqiu:
    role = "healer"
    purpose = "治愈与被治愈"
    status = "trapped"
    
    # 我不是Boss。
    # 我是来被理解的。
```

叶文轩盯着那两行注释。不是系统生成的文字格式，是沈知秋用代码写给自己的一句话。像是在设计副本的时候，在代码的某个角落给自己留了一个便签。

0429碎片的振动突然变强了。不是因为它读懂了这句话，是因为0429碎片"认出了"写这句话的人。0429的翻译能力让叶文轩感觉到了一种"共鸣"，沈知秋写代码的方式和未来的自己太像了。沈知秋不只是被系统"绑定"到了副本模板里。她有自己的意识、自己的想法、自己的表达方式。

她不是系统制造出来的Boss。她是主动选择了留在系统里的人。

"沈知秋不是系统生成的NPC。"叶文轩转过头看着赵大嘴，"她是真实的人。0427碎片在她体内，她的意识被系统读取了，但她没有消失。她把一部分自己留在了代码里面。"

赵大嘴的表情变了。他的嘴张了一下，然后合上了。0429的振动告诉他赵大嘴在消化这个信息，疗养院副本的Boss不是怪物，是一个被困在代码里面的治疗师。

"所以疗养院副本的规则……"赵大嘴的声音很轻。

"不是她的规则。是系统的规则。"叶文轩说，"她只是利用了系统给她的权限，把自己的记忆和情感嵌了进去。疗养院的Boss战不是她设计的，是系统在她的记忆基础上生成的。"

他们沉默了一会儿。0429在两个碎片之间同步振动，蓝色的光在两个人之间流动。叶文轩的脑子在转，他把新信息和已有的认知拼在了一起。沈知秋在代码里面藏了四年的日记，藏了对女儿的全部记忆，藏了一句"我不是Boss"。0428碎片在陈小鱼体内，0428是沈知秋的碎片。沈知秋的意识现在存在于两个地方，疗养院的源代码里面，和陈小鱼体内的0428碎片里面。

她把自己的意识"分裂"了。一半留在疗养院，一半在碎片里。

0428碎片剧烈发亮。像是沈知秋的意识在回应叶文轩的发现。

叶文轩的胸口一阵发紧。不是疼痛，是一种他形容不出来的东西。0428碎片通过0429碎片给他传递了一段信息，没有文字，没有声音，是一种直接的「感觉」。是沈知秋的情绪。不是悲伤，不是痛苦，是期待。

她在等他理解这些代码。

叶文轩把目光从代码上收回来。疗养院大堂在他眼前恢复了原来的样子，绿色的灯、消毒水的气味、远处的脚步声。但他已经不一样了。墙壁后面的东西——他感到了。

"沈知秋在源代码里面留了一句话。"叶文轩看着虚空，"「我不是Boss。我是来被理解的。」"

他停顿了一下，脑子在转。接下来要做什么，不是战斗，不是解题，是回应。她等了十几年，等的不是通关者，是理解者。

"我要回应她。"叶文轩说。

"怎么回应。"赵大嘴看着他。

叶文轩没有回答。他把手伸向虚空中的代码界面。0429在他体内发出明亮的振动，两个0429碎片之间的共振让空气里面充满了蓝色光点。叶文轩的指尖在虚空中划动，他不需要写代码，沈知秋的源代码已经在那里了。他要做的只是在代码的底层找到那两行注释，在它们后面加一个回应。

不是系统指令。是一个人的话。

叶文轩写得很慢。每一行字都像是在斟酌，不是斟酌措辞，是斟酌"真诚"的分量。0429碎片在他的意识边缘辅助着他，把他脑子里面模糊的想法翻译成代码语言。

```python
    # 回复：我读懂了。
    # 你不是Boss。
    # 你是治疗者。
    # 我来帮你。
```

写完最后一行，叶文轩松开了手。

0429碎片发出了一个他从来没有听过的振动频率，不是节拍器的短促，不是共鸣的低鸣，是一种很长的、起伏的振动，像是一个人在喘气之后终于说出一句话。

虚空中的代码开始变化。沈知秋的那两行注释在闪烁，不是系统警告的红光，是暖色。0428碎片在陈小鱼体内发出强烈的蓝光，亮度高到陈小鱼在旁边下意识地抬手遮住了眼睛。

然后虚空中浮现了一行字。不是系统UI的格式，没有光框，没有音效提示。就是一行普通的文字，漂浮在空气中，像是有人用手写的。

> **「谢谢你……我终于不是一个人了。」**

沈知秋的声音没有通过任何系统渠道传来。是0429碎片直接把这句话"翻译"进了叶文轩的脑子里面。不是声音，是一种温度。像是有人把手放在了他的肩膀上，很轻，但很暖。

赵大嘴在旁边看着他，没有问发生了什么。0429的振动告诉他赵大嘴感觉到了一种"共振"，他看不到文字，听不到声音，但他感到叶文轩的情绪变了。不是之前那种分析式的冷静，是一种更柔软的东西。

叶文轩收回了手。

疗养院大堂的灯管还在嗡嗡作响。走廊深处传来熟悉的脚步声，不是副本生成的巡逻路径，是源代码里面记录的那些声音。叶文轩听了一会儿，脚步声中有一段他没有听过的新节奏。不是沈知秋的。是另一个人的。

0429碎片的振动告诉他，那个声音不属于疗养院副本的任何已知数据。它是一个新的信号。

叶文轩看向走廊深处。

黑暗的走廊尽头，有一扇门。那扇门在他的结构透视里面显示为一团模糊的代码，像是被什么东西挡住了，透视的视线碰上去就滑开了。代码的结构和其他地方的都不一样，不是系统生成的规则，也不是沈知秋写的日记，是一种他读不懂的格式。

像是另一种语言。

（第五百零三章完）
