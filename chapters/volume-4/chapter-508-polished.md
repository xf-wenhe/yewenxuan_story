# 第五百零八章：终端机

房间的门在他们身后关闭了。

叶文轩站在终端前面。屏幕是暗的，没有闪烁的光标，没有系统提示语，只有一片均匀的深灰色，像是一面打磨过的金属板。终端的外壳是塑料的，边角有磨损，像是被很多人摸过。屏幕上没有浮尘。

0429碎片在他的胸口发出低沉的振动。不是在扫描——是在「认出」这个东西。

"这是什么。"赵大嘴走到他旁边。

"控制台。"叶文轩的声音很平，"疗养院的控制台。"

结构透视自动穿透了终端的外壳。第一层是物理结构：电路板、内存芯片、电源模块。第二层是系统接口：终端正在和一个他读不懂的「核心层」通信。第三层——

屏幕亮了。

不是系统UI的蓝色启动光。是白色。像是一个老式CRT显示器通电时的白光，从屏幕中心向外扩散，把整个终端面板映成了灰白色。屏幕上面的文字是等宽的、老式终端字体，黑色字符在白色背景上，没有任何装饰。

叶文轩看懂了第一行字。

> **「锚点档案系统 v1.0。欢迎，锚点A。」**

他的视线往下移。

屏幕分成了两个区域。左边一栏，右边一栏。左边栏目的标题是「锚点A」，右边栏目的标题是「锚点B」。两个栏目下面都是密密麻麻的字段——名字、能力值、状态、历史记录。

叶文轩先看左边。

```
锚点A档案
姓名：叶文轩
代号：洞察者
意识一致性：100%
核心能力：结构透视
能力等级：Lv.5
绑定碎片：0429
当前状态：活跃
闭环角色：逻辑端 / 分析者 / 出口寻找者
```

洞察者。100%。锚点A。这些他都知道。但「闭环角色」那一行——逻辑端 / 分析者 / 出口寻找者——这是他第一次在「系统层面」看到自己角色的定义。不是赵大嘴用0429碎片翻译给他的，不是他推论出来的，是系统自己记录的。白纸黑字。

他看向右边。

```
锚点B档案
姓名：赵磊
代号：暗行者
意识活跃度：85%
核心能力：概率扭曲
能力等级：Lv.3（抑制中）
绑定碎片：0429
当前状态：活跃 / 认知抑制
闭环角色：非理性端 / 概率变量 / 出口决策者
```

赵大嘴凑了过来，把脸凑到了屏幕前面。他的眼睛从左到右扫了一遍，嘴巴张开了。

"暗行者。"赵大嘴的声音很轻，"我代号是暗行者。"

叶文轩没有说话。他的目光钉在赵大嘴档案的第三行上——意识活跃度：85%。以及第五行——能力等级：Lv.3（抑制中）。括号里面的两个字很小，但结构透视的放大功能让它们变得清晰。

抑制中。

0429碎片在他胸口的振动变强了。不是紧张，是一种「确认」的节奏。0429在说这就是答案。这就是他一直想知道的东西。赵大嘴的能力不是天生弱，是被抑制了。认知抑制把他的能力锁在了Lv.3。

"轩哥。"赵大嘴的声音从旁边传来，"后面那个括号里写的什么。"

"认知抑制。"叶文轩直接说了。

赵大嘴的嘴合上了。他没有追问。他清楚这个词的含义——系统在修剪他的记忆、压制他的能力，防止他「过早觉醒」。0429碎片在他体内振动着，0429在告诉他这些档案是系统自己写的，不是未来的叶文轩写的，是系统的「底层配置文件」，在闭环建立的时候就存在了。

赵大嘴的能力从一开始就被锁住了。

"85%的意识活跃度。"叶文轩读出了声，"意思是你的意识有15%被抑制了。认知抑制占用了那15%。"

赵大嘴沉默了一会儿。他的视线在屏幕上移动，像是在寻找什么。然后他的目光停在了「闭环角色」那一行：非理性端 / 概率变量 / 出口决策者。

"出口决策者。"赵大嘴重复了一遍，"什么意思。"

"意思是——"叶文轩的声音顿了一下，"在终局中，选择「出口」的人不是你。但选择「走哪条路到出口」的人是你。"

赵大嘴没有马上理解。他的眉头皱了起来，嘴巴张开，像是在消化这句话。0429的振动在说让我解释。但叶文轩摇了摇头。现在不是解释的时候。

他的目光移到了屏幕底部。两个档案的下方，各自有几个「按钮」——不是图形按钮，是文字链接。左边锚点A的栏目下面有三个链接：「查看能力详情」「查看闭环日志」「退出」。右边锚点B的栏目下面有三个链接：「查看能力详情」「查看抑制参数」「退出」。

叶文轩的目光在右边的「查看抑制参数」上停住了。
他看向赵大嘴。

"大嘴。你想看吗。"

赵大嘴没有立刻回答。他盯着那个链接看了大概三秒。然后他点了点头。

"看。"

叶文轩伸手指了一下「查看抑制参数」。屏幕上的文字没有变化——但右边栏目下方的区域刷新了。不是弹窗，不是新页面，是同一块区域的内容被替换了。终端没有图形界面。所有的交互都是纯文本的。

```
锚点B · 认知抑制参数
抑制类型：记忆修剪 + 能力锁
抑制触发条件：锚点B同时感知到「锚点A」与「闭环」概念
抑制持续时间：0.3秒 ~ 永久
当前抑制强度：中等（松动状态）
抑制历史记录：
  第01次循环：抑制建立。意识活跃度降至40%。
  第02-07次循环：抑制维持。意识活跃度波动30%-60%。
  第08-17次循环：抑制松动。意识活跃度逐步回升。
  第18次循环（当前）：意识活跃度85%。抑制持续减弱中。
手动解除选项：可用
手动解除条件：两个锚点的共识
手动解除风险：锚点B可能经历记忆恢复冲击。冲击程度与当前抑制强度成反比。
```

叶文轩一行一行地读。抑制建立。抑制维持。抑制松动。第18次循环。

他看着最后一行——手动解除选项：可用。手动解除条件：两个锚点的共识。手动解除风险：锚点B可能经历记忆恢复冲击。

叶文轩的视线从屏幕上移开，看向赵大嘴。

赵大嘴的脸色很平静。不是他平时那种嬉皮笑脸的平静，是一种叶文轩不太熟悉的平静。0429碎片在他胸口的振动很稳，没有卡顿，没有波动，像是赵大嘴的脑子里面很安静。

"所以我的脑子卡顿——"赵大嘴的声音很轻，"是系统在修我的记忆。"

"不是修。"叶文轩说，"是锁。你的记忆没丢。只是被关在了一个门后面。门是虚掩着的——你偶尔能推开一条缝。那就是卡顿的时候。"

赵大嘴沉默了很久。

终端屏幕上的文字还在亮着。白色背景，黑色字符，安静地躺着。叶文轩能感觉到0429碎片在两个方向上的振动——他自己身上的和赵大嘴身上的——它们之间有一条看不见的线，0429在两根线上来回振动，像是一个在两个端点之间传递信息的信号。

"解除条件写的是什么。"赵大嘴问。

"两个锚点的共识。"叶文轩重复了屏幕上那一行字。

"什么意思。"

"意思是——"叶文轩看着赵大嘴，"我需要你同意。你同意解除认知抑制，系统才会放行。一个人同意不够。必须两个人都同意。"

赵大嘴没有说话。他把目光从屏幕上移开，看向房间的墙壁。墙壁是灰色的，没有代码流，没有数据标记，就是普通的灰色墙面。0429的振动在赵大嘴胸口轻微地震着，0429在说我在。我在帮你。我在等你的决定。

"解除之后会怎么样。"赵大嘴问。

"记忆恢复冲击。"叶文轩把屏幕上的那一行读了出来，"你的脑子会接收所有被锁住的记忆。第一次循环的、第十七次循环的、所有循环中你选择当拖油瓶的理由。一次性全部进来。"

"然后呢。"

"然后你就不再是你了。"叶文轩的声音很平，"或者说——你变成了「完整的你」。现在的你是被修剪过的你。解除后的你——是选择当拖油瓶的你。"

赵大嘴的嘴张开了，又合上了。他的目光在房间里移动——灰色的墙，角落里的阴影，天花板上的一盏旧灯。0429的振动在他的胸口变得很慢，很沉，像是在思考。

"轩哥。"赵大嘴的声音很轻，"你说我解除之后……还记得什么。"

"全部。"叶文轩说，"你记得第一次循环的选择。记得你每次选C的时候在想什么。记得你为什么选择当拖油瓶。"

赵大嘴沉默了很久。

"我不想现在解除。"赵大嘴的声音很轻，但很确定。

叶文轩看着他。

"不是现在。"赵大嘴说，"等终局。那时候……我们两个一起选。那时候解除，记忆冲击有你在，我不怕。"

叶文轩的胸口一阵发紧。0429的振动突然变强了——不是焦虑，是共鸣。0429在说这就是答案。这就是两个锚点的共识。不是现在。是终局。

他的视线回到屏幕上。

屏幕底部的文字在闪烁。不是红色警告，是白色的闪烁，像是一个确认的光标。屏幕上浮现了一行新的文字：

> **「认知抑制可以手动解除。解除条件：两个锚点的共识。」**

叶文轩看着那行字。赵大嘴也看着那行字。

0429碎片在两个身体里面同时发出了一声低沉的振动——不是脉冲，不是节拍，是一种很长的、共振的嗡鸣。两个0429碎片之间的频率同步到了同一个波段，像两个音叉被同一个声音敲击。

终端屏幕上的文字在共振中发亮。
然后屏幕暗了下去。

不是关机。是「等待」。终端完成了它的任务——把档案展示给了两个锚点。接下来是等他们做出选择。

叶文轩和赵大嘴站在终端前面。房间里面的空气很沉，没有风，没有声音，只有0429碎片在他们胸口发出的低振动。

叶文轩看向赵大嘴。

赵大嘴也在看他。他的眼睛里面有一种叶文轩从来没有见过的东西——清澈，安静，像是一个平时总是在笑的人突然不笑了，然后你才发现他笑的时候眼睛里面也有很沉的东西。

"轩哥。"赵大嘴的声音很轻，"等终局的时候……我们一起选。"

叶文轩 nod 了一下。
他们转身离开房间。

身后的终端屏幕暗着，像一个沉睡的东西。0429的振动在两人胸口平稳地运转着，频率一致，像是一座桥的两端，在等一个信号。

叶文轩走出疗养院的时候，天还没有亮。灰色的天光从远处的云层里面漏出来，照在疗养院的外墙上。水泥墙上的裂纹在灰光里面看起来很清晰，像一张地图。

他的背包在震动。

裂隙核心和泰迪熊在背包里面发烫，两个碎片载体在同步振动，像是有什么东西在试图从里面「出来」。

但不是现在。

叶文轩看了一眼疗养院的大楼。在大楼的顶层，有一扇窗户，灯亮着。窗户的后面有一个模糊的人影，站在灯光的边缘，看不清脸。

沈知秋。
她看着他们离开。

叶文轩收回目光，和赵大嘴并肩走向远处。0429的振动在两人胸口同步着，像一颗心跳，两个地方，同一个节拍。

（第五百零八章完）
