# 第五百二十四章：防火墙人格

白色的空间中，那个身影越来越近。叶文轩的洞察之眼在第一时间「透视」了对方的结构。是「人」。但又不是普通的人。0429碎片在他胸口剧烈振动，翻译速度比任何时候都快。「林渊。」赵大嘴的声音在旁边响起，很轻。「那个疗养院的记录者。」

叶文轩没有回答。他的注意力全在那个正在走近的身影上。距离拉近之后，他看清了。就是林渊。和之前见过的完全一样。白大褂。黑框眼镜。表情平淡。但叶文轩的洞察之眼告诉他，这个林渊的「底层结构」和之前遇到的那个不一样。之前的林渊是一个「记录者」。系统的功能模块。这个林渊的底层结构更复杂。更像……一个人。或者说。

更像他自己。林渊停在了距离他们三米远的地方。他没有说话，先看了一眼叶文轩，又看了一眼赵大嘴，目光在两个0429碎片上来回扫了一次。「你看到我的结构了。」林渊说。不是问句。「你是谁？」叶文轩问。林渊沉默了两秒。「你看到的没有错。我不是记录者。也不是NPC。我是……」

他停了一下。「我是防火墙。」

叶文轩的后背一僵。0429碎片的振动在胸口跳了一下「撞」了一下。「防火墙？」赵大嘴接话，眉头皱了起来。「什么意思？」

「2147年。」林渊说。「未来的你建立系统的时候，把自己的「保护本能」从主体意识中分离了出来。形成了一个独立的意识模块。这个模块的职责是，保护系统不受外部攻击，保护系统不被自己改写。」

他看向叶文轩。目光穿过镜片，很平。「我就是那个模块。未来的你把我「造」了出来，给了我名字，给了我身份，把我嵌进了系统的防火墙层。从2147年到2026年，我在防火墙的后面看着一切。」

叶文轩的脑子在转。碎片在帮他翻译：把林渊说的每一个字都映射到他能理解的逻辑框架上。防火墙人格。未来自己的保护本能。分离出来的独立意识。这和他之前接触到的「林渊」，那个疗养院的记录者，是什么关系？「疗养院的那个你。」叶文轩问。「也是防火墙？」

「是。」林渊说。「同一个模块。两个接口。防火墙的主体驻守在系统核心层，负责监控和防御。记录者接口投影到副本中，负责「观察」玩家的行为。你在疗养院遇到的那个我。是防火墙的一个「投影」。」

叶文轩看着他。三米。很近的距离。他能感觉到林渊身上有一种很奇怪的东西。是一种「频率」。和他的意识频率很接近。但是「邻近」的频率。像两个电台调到了同一个波段，但不是同一个台。「所以你一直在看着我。」叶文轩说。「从你进入系统的第一天起。」林渊说。「防火墙的职责是监控所有异常。你，第18次循环的锚点A，是我们见过的最大的异常。」

「因为你打破了闭环。」

林渊没有否认。他的表情没有变化，但0429碎片的翻译速度突然变慢了。像是林渊说的那句话，包含了太多「系统语言」，碎片需要更多时间处理。「防火墙有一个「本能」。」林渊继续说。「保护系统。阻止任何可能破坏系统的行为。当你在V3的结尾做出「打破闭环」的选择时，防火墙本应该立刻启动防御。但……」

他停了一下。「但防御没有启动。」叶文轩接话。「因为防火墙的底层逻辑……是你自己写的。」林渊说。「未来的你在代码中埋了一个「后门」。防火墙在判断「是否防御」之前，必须先执行一个「身份验证」。而那个验证的答案，是「叶文轩」。只有叶文轩本人才能绕过防火墙的防御。」

叶文轩的心脏猛地停跳了一拍。「所以你放任我打破闭环。」他说。「不是放任。」林渊纠正道。「是「允许」。因为你是系统的设计者。你有权修改自己的设计。」

赵大嘴在旁边一直没有说话。他的表情很复杂。像是听到了太多超出理解范围的东西，脑子在努力消化。0429碎片在他的胸口发着蓝光，亮度比平时低了一些。像是在「休眠」状态，只保持最低限度的翻译功能。「大嘴。」叶文轩没有看他。「0527碎片还在你体内。0429是翻译。0527是什么？」

「0527。」林渊替赵大嘴回答了。「锚点的碎片。功能是「概率感知」。它能「感知」概率的流动，是锚点能力的底层支撑。」

叶文轩看向赵大嘴。赵大嘴的嘴张着。他的右手不自觉地握紧了。掌心里0429碎片的蓝光被他攥在手心，从指缝里漏出来。「所以0527和0429不是同一个碎片。」叶文轩说。「不是。」林渊说。「0429是「翻译」，把叶文轩的意识翻译成系统语言。0527是「感知」，感知概率的流动。两个碎片配合，才是完整的锚点B。」

叶文轩的洞察之眼自动运行了。他「透视」了赵大嘴的体内结构。0429在胸口，0527在腹腔。两个碎片之间有一条细蓝色的「链路」，像一根光纤，在体内连接着两个节点。链路很稳定。没有断。但链路的外围有一层灰色的「干扰层」。认知抑制。干扰层的厚度不均匀，有些地方薄得像蝉翼，有些地方厚得像墙壁。0429碎片一直在用自己的能力「腐蚀」那层干扰层。

0429碎片在保护赵大嘴。叶文轩把目光从赵大嘴身上移开，回到林渊身上。「你在终局会做什么？」他问。「防火墙的职责。」林渊说。「保护系统。阻止任何可能破坏系统的行为。」

赵大嘴的眉头皱紧了。「你是说你站在系统那边？」

「系统就是叶文轩。」林渊说。「我就是叶文轩的一部分。防火墙的存在是为了保护「闭环」不被外部力量摧毁。但「闭环」本身的设计，是未来的叶文轩为了「保护人类」而写的。所以防火墙保护的不是一个「邪恶的系统」。防火墙保护的是一个「有意义的系统」。只是这个系统的「意义」，现在的你还不能完全理解。」

叶文轩的后背渗出了冷汗。0429碎片的振动突然加速了。像是感觉到了什么。「你的意思是，系统的一部分不想让我重构闭环。」叶文轩说。「不是「不想」。是「在评估风险」。」林渊纠正道。「重构闭环是一个从未发生过的操作。防火墙的逻辑是：任何未经验证的操作都有风险。风险等级未知。因此需要「阻止」，直到风险被确认可控。」

他看向叶文轩。目光在镜片后面动了一下。「但防火墙的底层逻辑有一个漏洞。是你自己留下的。防火墙只能阻止「外部」的行为。不能阻止「设计者本人」的行为。当你，锚点A，和锚点共同选择的时候，防火墙的「身份验证」会确认你的身份，然后……」

他停了一下。「然后怎么样？」赵大嘴忍不住问。「然后防火墙会切换到「支持」模式。」林渊说。「因为重构闭环 = 你作为设计者在「升级自己的设计」。防火墙不会阻止设计者升级自己的设计。」

白色的空间安静了几秒。叶文轩在消化这句话。0429碎片在帮他翻译，但逻辑链条已经清晰了。防火墙是未来的自己设计的保护机制。保护机制的核心逻辑是「识别设计者」。当设计者（叶文轩）和锚点B（赵大嘴）共同选择的时候。防火墙会认出叶文轩的身份，然后支持他的选择。所以终局的关键是「让防火墙认出自己」。叶文轩看向赵大嘴。

赵大嘴也看着他。0429和0527两个碎片在两人体内同时振动，频率渐渐同步了。「大嘴。」叶文轩说。「0527碎片在你体内。它和0429配合，0429翻译，0527感知概率。在终局的关键时刻，0527能帮你「感知」到正确的选择。」

赵大嘴「嗯」了一声。他的右手握成了拳，0429碎片的蓝光从他的指缝里透出来。「轩哥。」赵大嘴的声音比刚才稳了一些。「0527……我体内有0527碎片的事，你什么时候知道的？」

「刚才。」叶文轩说。「林渊告诉我的。」

赵大嘴沉默了一会儿。他的目光从叶文轩脸上移开，看向虚空中某个方向。「我体内不止0429。」赵大嘴自己说。「0527也在。我不知道它们是什么时候进去的。系统没有告诉我。」

叶文轩看着他。赵大嘴的侧脸线条平时总是被嬉皮笑脸的表情覆盖，此刻露出来的部分很安静。很真实。「但0527一直在。」赵大嘴继续说。「我能感觉到。有时候脑子卡顿的时候，卡顿的那三秒里面，我能感觉到一个「声音」在帮我撑着。撑着我不要完全晕过去。现在我知道了。那是0527。」

0429碎片在胸口振动了一下。像是一个确认。叶文轩看向林渊。林渊的表情没有变化，但他的目光在赵大嘴身上停留了更长的时间。「0527碎片是锚点的核心组件。」林渊说。「它在你体内的作用比0429更基础。0429是「翻译」。0527是「感知」。翻译可以被干扰。感知不会。0527一直在帮你对抗认知抑制，在你看不到的地方。」

赵大嘴的呼吸停了一下。「我一直以为我在「扛」。」赵大嘴说，声音很轻。「原来0527一直在帮我扛。」

「不是「扛」。」林渊说。「是「配合」。0527感知概率，0429翻译意识。两个碎片一起，维持你的认知稳定。你没有想象中那么弱。」

赵大嘴没有回答。他的嘴唇抿成了一条线。眼睛里面有一种东西在闪。但是更沉的东西。叶文轩看着他。他第一次在赵大嘴的脸上看到这种表情。像是突然知道了自己的「分量」。是另一种东西。「林渊。」叶文轩把目光转回林渊身上。「你在终局中的角色是什么？」

林渊沉默了两秒。「防火墙的职责是保护系统。」他重复了一遍之前的话。「但当锚点和锚点共同选择的时候，防火墙会切换到支持模式。这意味着，在终局中，我会站在你这边。」

林渊的语气是陈述句。「为什么？」叶文轩问。「防火墙的逻辑不是「阻止未经验证的操作」吗？重构闭环是未经验证的操作。」

「因为身份验证通过了。」林渊说。「你的身份 = 设计者。设计者的选择 = 最高优先级。防火墙的逻辑是：设计者的选择优先于一切保护规则。」

白色的空间再次安静下来。0429碎片在叶文轩胸口平稳地振动。叶文轩的后背还是冷的。冷汗没有干。但他的脑子很清楚。比进入终局以来的任何时候都清楚。防火墙会站在他这边。是出于「逻辑」。因为他是设计者。因为未来的自己写下的代码中，设计者的优先级高于一切。但这个逻辑有一个前提。他必须在终局中「证明」自己是设计者。

怎么证明？源代码中有一个提示。`if anchor_a.choice == C and anchor_b.choice == C:`。两个锚点共同选择C。这就是身份验证的触发条件。所以终局的关键是「完成共识」。叶文轩看向赵大嘴。赵大嘴也在看他。0429和0527的振动在两人之间形成了一条看不见的「链路」。

是意识的链路。两个锚点的意识，在两个碎片的辅助下，正在「对齐」。「大嘴。」叶文轩说。「0527在你体内。它在帮你对抗认知抑制。0429在翻译。两个碎片一起，在「撑」着你的意识。」

赵大嘴「嗯」了一声。他的右手依然握着0429碎片，蓝光从指缝里漏出来，在他的脸上投下一片淡蓝色的阴影。「我从来没有觉得这么清醒过。」赵大嘴说。「真的。」

叶文轩看着他。赵大嘴的眼睛里面那种「沉」的东西更明显了。是壳下面的东西。「林渊。」叶文轩转向林渊。「防火墙在终局中会做什么？具体一点。」

林渊沉默了两秒。「终局中有三个阶段。」他说。「第一阶段：认知抑制的最终爆发。第二阶段：锚点共识的验证。第三阶段：重构执行。防火墙在每个阶段都有不同的职责。」

「第一阶段。」林渊继续说。「认知抑制会在终局开始后的72小时内达到峰值。赵大嘴的卡顿频率会从每五分钟一次变成每分钟一次。每次持续三到五秒。在这个阶段，防火墙的职责是「监控」，监控锚点的状态，确认锚点没有完全被抑制。」

「第二阶段。」林渊的声音没有起伏。「锚点共识的验证。你和赵大嘴需要同时选择C。这个过程防火墙会「观察」，确认你们的选择是「清醒的」而不是「被系统操控的」。如果验证通过，防火墙切换到支持模式。」

「第三阶段。」林渊停了一下。「重构执行。防火墙会「协助」，保护重构过程不被系统内部的反抗力量打断。」

叶文轩的后背渗出了冷汗。「反抗力量？」

「系统不是一个铁板一块的整体。」林渊说。「未来的你在设计系统的时候，把自己的意识「分」成了几个部分。防火墙是其中一个。还有一部分，是「维持闭环」的意志。那部分意志认为闭环是「必要的」。它会试图阻止重构。」

叶文轩的脑子在转。0429碎片在帮他整理逻辑。未来的自己把自己的意识「分割」了，一部分留在系统中作为「维持闭环」的意志，一部分分离出来成为「防火墙」。两部分都在系统中运行。一部分想维持现状。一部分在设计「保护机制」，但这个保护机制本身可以被设计者本人激活。所以终局的本质是「和未来的自己对弈」。林渊看着他。

「你理解得很快。」林渊说。「防火墙人格，就是你的「自我保护」的本能。那部分本能被分离出来之后，在系统内部形成了一个独立的意识。就是我。」

他停了一下。「在终局中……我会选择保护你。因为你就是我。」

叶文轩看着他。三米远的距离。林渊的表情没有变化，但他的声音里面有一种东西。是一个人在说话。一个认识了他很久的人。「你不是NPC。」叶文轩说。「不是。」林渊说。「我是你的一部分。只是被分离出来了。」

白色的空间中，远处传来了系统的倒计时。还有七分钟。白色大门的能量波动从门的方向传来「催促」。叶文轩深吸了一口气。0429碎片在他胸口平稳地振动。0527在赵大嘴体内同步振动。两个碎片，两个锚点，在同一个频率上。他看向赵大嘴。赵大嘴也在看他。赵大嘴的表情比刚才稳了。像是知道了自己的「分量」之后，那种不确定消失了。

「大嘴。」叶文轩说。「0527在帮你。0429在帮我。两个碎片在配合。在终局中，你的意识不会孤军奋战。」

赵大嘴笑了一下。很浅。很真。「我知道。」赵大嘴说。「0527刚才「说」了一句话。在我脑子里。是一种「感觉」。它说：「不会让你一个人。」

叶文轩看着他。0429碎片在胸口振动了一下。像是确认。虚空中，林渊的身影开始淡去。是「撤回」。他的存在依赖于防火墙层，防火墙层现在要退到后台了。因为终局阶段一即将开始，防火墙要从「前台」切换到「后台」模式。「林渊。」叶文轩叫了他一声。淡去的身影停住了。「在终局中。」叶文轩说。「你会帮我们吗？」

林渊沉默了两秒。「防火墙的逻辑是「保护系统」。但系统的设计者是你。当设计者选择「重构」的时候，保护系统 = 保护重构。所以是的。我会帮你们。」

他的身影继续淡去。最后一句话从消散的光影中传出来：「赵大嘴的卡顿在终局时会加剧。0527能帮他扛住大部分。但最关键的那三秒，你需要亲自稳住他的意识。锚点的力量不是用来分析的。是用来「稳定」的。记住。」

光影完全消失了。白色的空间中只剩下叶文轩和赵大嘴两个人。0429和0527的振动在两人体内同步跳动。远处的白色大门越来越亮。倒计时的嗡鸣声从门的另一侧传来。还有五分钟。叶文轩看向赵大嘴。赵大嘴的右手依然握着0429碎片，蓝光从指缝里漏出来。0527在腹腔中振动，频率和0429同步。两个碎片的链路在体内清晰可见。

0429翻译，0527感知，共同维持他的认知稳定。「大嘴。」叶文轩说。「0527刚才「说」了什么？」

赵大嘴沉默了一会儿。「不是「说」。是一种感觉。像有人在脑子里面撑了一把伞。撑着我不倒下去。它说：「不会让你一个人。」」

叶文轩看着他。赵大嘴的眼睛里面那种「沉」的东西更深了。是一种他从未见过的清澈。「轩哥。」赵大嘴的声音很平静。「我刚才听林渊说0527一直在帮我扛着认知抑制……我突然想起了一件事。」

「什么事？」
