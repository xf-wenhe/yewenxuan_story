# NPC 名册

## 第一卷（Ch.1-80）涉及的主要NPC

---

### NPC-01：系统引导者 · "引路人"

| 项目 | 内容 |
|------|------|
| 姓名 | 表面名：林渊（玩家可见的名字） |
| 真实身份 | 系统的表层化身。是真正的"主神"，而是系统投射的一个"引导人格" |
| 外貌 | 约30岁，干净利落的短发，灰色制服，表情永远平淡如水 |
| 性格 | 彬彬有礼但毫无感情，回答问题精确但永远只说一半，偶尔冒出一句让叶文轩觉得"过于了解我"的话 |
| 出场章节 | Ch.5, Ch.10, Ch.40, Ch.80 |
| 与主角关系 | 引导者 → 被引导者，后期叶文轩开始怀疑他的"不知道"是装的 |
| 关键台词 | "欢迎来到无限世界。在这里，你的过去不再重要。你的选择，将定义你的未来。" |
| 隐藏设定 | 林渊的语气和用词风格。叶文轩觉得像某个他认识的程序员。是的，那是未来的叶文轩自己（闭环的echo） |

### NPC-02：疗养院副本 · 院长

| 项目 | 内容 |
|------|------|
| 姓名 | 沈知秋 |
| 真实身份 | 副本Boss，疗养院的院长，一个疯狂的"治疗者" |
| 外貌 | 50岁左右，穿白大褂，温和的笑容，手里永远拿着一支笔 |
| 性格 | 表面温和理性，内在疯狂。认为"痛苦是治疗的必要过程"，把病人当成实验品 |
| 出场章节 | Ch.15-20（疗养院副本） |
| 与主角关系 | Boss vs 玩家，叶文轩在副本中理解了她的动机（是一个简单的恶人） |
| 关键台词 | "你不懂。痛苦是惩罚。痛苦是治愈的第一步。" |
| 伏笔 | 沈知秋的疯狂背后有系统的暗示。她的"治疗方案"实际上是在测试玩家的意志力（系统筛选机制的一部分） |

### NPC-03：疗养院副本 · 小病人

| 项目 | 内容 |
|------|------|
| 姓名 | 朵朵（化名） |
| 真实身份 | 副本中的关键NPC，一个"被治疗"的小女孩 |
| 外貌 | 约8岁，扎双马尾，脸色苍白，总是抱着一个破旧的泰迪熊 |
| 性格 | 沉默寡言，但对叶文轩表现出异常的信任 |
| 出场章节 | Ch.17-20 |
| 与主角关系 | 副本中的"情感锚点"。叶文轩在她身上看到了自己的女儿 |
| 关键情节 | 叶文轩在副本的最后面临选择：救朵朵（拖延时间，增加通关难度）或先完成任务。叶文轩选择了救朵朵。 |
| 伏笔 | 朵朵是真人。她是系统生成的"情感测试NPC"。但她的反应是真实的（基于叶文轩的情感投射）。 |

### NPC-04：民国鬼镇副本 · 茶馆老板

| 项目 | 内容 |
|------|------|
| 姓名 | 王老头 |
| 真实身份 | 副本中的信息NPC，知道很多规则但不愿意说全 |
| 外貌 | 70岁左右，穿长衫，满脸皱纹，永远在泡茶 |
| 性格 | 世故圆滑，话里有话，关键时刻才会吐露关键信息 |

| 与主角关系 | 信息提供者 → 叶文轩通过分析他的话语推断出隐藏规则 |
| 关键台词 | "这地方的规矩……说了你也不信。但你可以试试看。" |
| 伏笔 | 王老头的话中有很多"双关"。他既是副本NPC，也是系统用来测试玩家分析能力的工具。他的"不愿意说全"是系统设计的。 |

### NPC-05：毕业考核副本 · 考核官

| 项目 | 内容 |
|------|------|
| 姓名 | 无（系统不提供名字） |
| 真实身份 | 系统直接操控的考核实体，没有独立人格 |
| 外貌 | 模糊的人形轮廓，没有面部特征，声音像是多人重叠 |
| 性格 | 严格、冰冷、只按规则执行 |
| 出场章节 | Ch.71-80 |
| 与主角关系 | 考官 vs 考生，叶文轩在考核中发现了系统的"异常" |
| 关键情节 | 考核中出现了叶文轩"不应该知道的规则"。考核官似乎知道叶文轩会做什么 |
| 伏笔 | 考核官的"预知"是闭环的体现。系统在执行一个已经被"写好"的考核 |

### NPC-08：孙鹏

| 项目 | 内容 |
|------|------|
| 姓名 | 孙鹏 |
| 真实身份 | 现实世界地下实验室的疯狂科学家，做意识实验（1998年27岁起主持实验室，系统内活27年，现实约五十五岁）；系统内是觉醒者（等级五级，意识活跃度+567%）。**隐藏真相（Ch.332揭示）：不是未来文明投射的意识，而是未来文明投射系统时误带入的"变数"，一段比未来文明更早的意识，伪装成玩家在系统中活了27年** |
| 外貌 | 现实约五十五岁，瘦，有皱纹、有白发、有疲惫，颧骨凸出，眼有红血丝，手腕上有三厘米旧疤 |
| 性格 | 系统内冷静、有耐心，懂得评估对手与战略性撤退；现实里执着到近乎偏执，为了找到小梅、打开时间之门，可以等二十七年 |
| 出场章节 | Ch.31-47（第一卷，浮石对峙/收集0428碎片）、Ch.322-337（第三卷真相揭示）、Ch.339-359（真实世界篇） |
| 与主角关系 | 敌人 → 合作：现实里把赵磊（赵大嘴）当作实验对象（Ch.325）；系统里试图夺取0428碎片以追踪0429；V3真实世界与叶文轩、赵磊、何冰合作（Ch.343协议：不伤害任何人），一起去找他妻子小梅 |
| 关键情节 | Ch.42-44：浮石对峙，赵大嘴封印瓦解、锚点激活后他撤退并刻字宣战；Ch.331-336：揭示他想用0429碎片打开时间之门；Ch.343-351：与叶赵合作，进入大兴安岭残留空间/记忆海洋，见到小梅（0429碎片=妻子小梅的意识碎片，记录者碎片）；Ch.358：获小梅主意识碎片（信物）；Ch.359：分道南行 |
| 后续 | V3末与叶赵分道，南行寻找散落的0429碎片（Ch.359），未了结 |
