# 核心副本详细规则设计

> 写作时的关卡设计参考。包含每个副本的结构、威胁类型、谜题流程、Boss战机制、通关条件。
> **核心原则：副本是"有逻辑的危险环境"。威胁来自具体的怪物、陷阱和环境，而是违反抽象规则。死亡是有明确原因的。**

## 副本 #01：废弃疗养院

### 基本信息

| 项目 | 内容 |
|------|------|
| 难度 | ★（ solo 可过，但极难） |
| 推荐人数 | 1-3人 |
| 预计通关时间 | 2-3小时（现实时间） |
| 副本类型 | 主线副本（入局副本） |
| 核心主题 | 初识危险，第一次生死体验 |

### 副本背景

市郊一家废弃的精神疗养院，1998年关闭。院长沈知秋因对病人实施"非常规治疗"被曝光后失踪。疗养院被废弃后，当地居民报告夜间听到孩子的笑声和脚步声，但进入查看的人什么都没发现。

**系统的真实目的：** 这是系统在1997-1998年进行"环境引擎测试"的地点。沈知秋的"非常规治疗"恰好与系统的"压力测试"逻辑吻合。系统"利用"了她的理念，把她变成了副本Boss。

### 三层结构分析（叶文轩的洞察之眼视角）

叶文轩的职业能力是"看穿规则"。是**透视事物的结构模式**。他能看到环境的"底层逻辑"。怪物巡逻的规律、陷阱的触发条件、隐藏通道的存在。

#### 结构层1：环境结构（基础感知）

**照明结构：**
- 有灯光的房间 = 相对安全（治疗者不进入有灯光的房间）
- 黑暗走廊 = 危险（治疗者在黑暗中巡逻）
- 灯光的覆盖范围有限。玩家需要规划路线，避开黑暗区域

**巡逻结构：**
- 疗养院中有"治疗者"在巡逻。穿白大褂的人形怪物，面部模糊
- 治疗者的巡逻路线是固定的，但有"窗口期"。在特定时间点，两条巡逻路线会交叉，留下一个可以安全通过的间隙
- 叶文轩通过洞察之眼可以看到治疗者的巡逻路线（以视觉化的线条呈现）

**房间结构：**
- 亮着灯的病房 = 安全区（可以恢复少量生命值）
- 关着灯的病房 = 可能有治疗者，也可能没有
- 锁着的病房 = 需要找到钥匙或破门才能进入
- 某些病房有特殊物品（病历、钥匙、道具）

#### 结构层2：敌人结构（深度分析）

**治疗者：**
- 外形：穿白大褂的人形，面部模糊，动作机械
- 攻击方式：扑击（近战，造成20%伤害）、注射（远程，被扎到的玩家会被标记。3分钟后传送到地下室治疗室）
- 弱点：治疗者只在黑暗中活跃，进入灯光区域后会"停滞"。动作变慢，攻击频率降低
- 行为模式：固定路线巡逻，遇到玩家会追击，但追击距离有限（追出灯光范围后会放弃）

**沈知秋（Boss）：**
- 是战斗型Boss，是"环境操控型"Boss
- 她能控制疗养院的照明系统。让灯光闪烁、熄灭、改变位置
- 她通过控制照明来"困住"玩家。让玩家陷入黑暗，被治疗者包围
- 她的弱点：她的照明控制依赖于特定的"控制节点"。玩家找到并破坏这些节点，就能削弱她的能力

#### 结构层3：副本核心结构（深度洞察）

**出口条件：**
- "治愈完成"的含义：是理解治疗的本质
- 玩家需要找到沈知秋，通过对话让她意识到她的"治疗"方法的局限性
- 这是逻辑说服。沈知秋的力量来自她对"治疗理念"的信仰。如果玩家能证明她的理念有漏洞，她的力量就会削弱

**朵朵的特殊性：**
- 朵朵是真人。她是系统生成的"情感测试NPC"
- 她的反应基于叶文轩对女儿的情感投射
- 她偶尔会说一些"不在系统预设中"的话。像是她有某种自发的意识
- 她是副本的"情感锚点"。系统通过她测试玩家的意志力

### 副本流程

#### 阶段1：探索（0-30分钟）

**目标：** 了解副本环境，收集线索

**流程：**
1. 7名玩家进入疗养院一楼大厅
2. 系统广播告知基础威胁信息
3. 玩家自由探索。叶文轩选择单独探索三楼
4. 叶文轩在三楼发现院长办公室，洞察之眼激活

**关键事件：**
- 叶文轩发现办公室电脑，看到一行字："如果你看到这个，说明结构已经启动了。"
- 电脑字体 = 系统面板字体（伏笔）
- 2名玩家在探索中被治疗者捕获

#### 阶段2：建立安全区（30-60分钟）

**目标：** 找到一个安全的据点，分析已收集的信息

**流程：**
1. 叶文轩和老周（临时队友）回到一楼大厅
2. 发现大厅有2盏灯 = 基本安全
3. 与其他幸存者汇合（4人：叶文轩、老周、小樱、阿梅）
4. 分析线索。叶文轩开始建立"环境结构模型"

**关键事件：**
- 叶文轩通过洞察之眼透视出照明结构和巡逻路线
- 小樱提到在二楼遇到了"穿白大褂的女人"
- 叶文轩意识到那个女人 = 沈知秋

#### 阶段3：深入探索（60-90分钟）

**目标：** 找到朵朵，了解副本核心

**流程：**
1. 叶文轩和小樱探索三楼，找到朵朵的病房
2. 朵朵出现，透露关键信息："院长阿姨说做完治疗就可以回家了"
3. 叶文轩意识到朵朵是"情感测试NPC"
4. 沈知秋出现，和叶文轩对话

**关键对话：**
- 沈知秋解释她的"治疗理念"：痛苦是治愈的必要过程
- 叶文轩反驳：痛苦是治愈，是伤害
- 沈知秋："那你有什么更好的方法？"
- 叶文轩："……我不知道。但我知道你的方法有问题。"

#### 阶段4：危机（90-120分钟）

**目标：** 应对沈知秋的照明操控

**流程：**
1. 老周被治疗者注射，标记。3分钟后传送到地下室
2. 叶文轩带领团队前往地下室营救
3. 在地下室入口遇到沈知秋。她开始操控照明
4. 灯光开始闪烁、熄灭、改变位置。玩家被逼入黑暗区域
5. 叶文轩透视出照明控制节点，带领团队在闪烁的灯光中穿行

**Boss战第一阶段：照明操控战**

**Boss机制：**
- 沈知秋不直接攻击玩家。她控制照明系统
- 每30秒，她改变一次照明布局（熄灭某些灯、打开某些灯、改变灯光范围）
- 玩家必须在灯光保护下移动，避开黑暗中的治疗者

**叶文轩的应对：**
- 洞察之眼实时透视照明结构的变化
- 叶文轩在脑海中建立"照明变化模型"。预测沈知秋的下一次照明改变
- 带领团队在灯光变化中前进

#### 阶段5：Boss战第二阶段：逻辑对话（120-150分钟）

**触发条件：** 团队到达地下室，找到老周

**Boss机制转变：**
- 沈知秋不再操控照明。她开始和叶文轩对话
- 这是"战斗"，是"说服"。沈知秋要求叶文轩证明她的方法有错
- 对话的内容涉及：痛苦的哲学、治愈的本质、"治疗"的定义

**对话的"游戏化"：**
- 对话不是纯文字。沈知秋会创造"场景"让叶文轩体验痛苦
- 每轮对话，她创造一个情境。让叶文轩面对自己的痛苦记忆
- 叶文轩必须在"体验"中保持理性，找到反驳点

**关键对话节点：**
1. **第一轮**：沈知秋创造一个"疼痛场景"。叶文轩感受到剧烈的疼痛（虚拟的）。叶文轩的分析：疼痛是信号，是治愈。
2. **第二轮**：沈知秋创造"记忆场景"。叶文轩看到自己最痛苦的记忆（女儿的疏远）。叶文轩的分析：面对痛苦不等于治愈痛苦。
3. **第三轮**：沈知秋创造"选择场景"。叶文轩必须选择"治疗自己"或"治疗朵朵"。叶文轩选择了治疗朵朵。但他说："治疗是消除痛苦。是帮助面对痛苦。你的方法在'消除'，是在'帮助'。"

**沈知秋的"失败"：**
- 叶文轩的逻辑说服让沈知秋的信念产生了裂痕
- 她的照明控制开始出现"错误"。灯光不稳定，有些灯熄灭了没有再亮
- 她沉默了很久，然后说了一句："……你比我见过的人都像她。"

#### 阶段6：通关（150-180分钟）

**通关条件：** 沈知秋"放弃"对疗养院照明系统的控制

**过程：**
- 沈知秋主动关闭了照明控制系统
- 她说："……也许你是对的。也许……我一直在逃避。"
- 疗养院的出口出现。一扇普通的门，通向疗养院的花园
- 朵朵在花园里等叶文轩

**关键选择：**
- 叶文轩可以选择：1. 立即离开（效率通关）2. 陪朵朵多待一会儿（情感选择）
- 叶文轩选择了2

**通关评价影响：**
- 效率通关 = S级评价
- 情感选择 = B级评价（系统"惩罚"了情感选择）
- **但这个B级评价是叶文轩的骄傲**。他选择了"对"的事，是"高效"的事

## 副本 #02：民国鬼镇

### 基本信息

| 项目 | 内容 |
|------|------|
| 难度 | ★★★ |
| 推荐人数 | 2-3人（叶文轩+赵大嘴固定组队） |
| 预计通关时间 | 3-4小时 |
| 副本类型 | 主线副本 |
| 核心主题 | 双层世界探索、团队配合、真相碎片 |

### 副本背景

民国二十六年（1937年），一个边陲小镇一夜之间所有居民消失。只留下空荡荡的房屋、到处可见的诡异符号、和一口古井。

**系统的真实目的：** 这个副本是系统在1937年进行"环境引擎测试"的地点。系统选中了这个小镇，测试"双层结构"。表层世界和灵体世界的并行存在。

### 双层世界结构

#### 表层世界（玩家默认视角）

**环境特点：**
- 白天相对安全。可以自由探索房屋、收集信息
- 天黑后危险增加。灵体在表层世界活动
- 有固定光源（煤油灯、月光）。但光源范围有限，黑暗区域有潜伏的危险

**表层世界的威胁：**
- **灵体入侵**：天黑后，灵体会从古井中涌入表层世界
- **红衣女人**：一个强大的灵体，穿着红色旗袍，在镇上巡逻。她是"不能看"就死。她是**高威胁敌人**，看到她会触发战斗（或需要逃跑）
- **哭声来源**：夜晚能听到哭声，追踪哭声会找到灵体的聚集点。可以消灭灵体，但也可能遭遇多个灵体

#### 深层世界（赵大嘴的灵视视角）

**赵大嘴的特殊能力：**
- 他能同时感知表层和深层两个世界的"结构"
- 他能在深层世界中看到额外的"路径"。一些在表层世界是墙壁的地方，在深层世界是通道
- 他能感知灵体的"活动规律"。提前警告队友哪里有灵体

**深层世界的威胁：**
- **遗忘者**：深层世界中的灵体，会抹去玩家的"存在感"。被遗忘者触碰的玩家会暂时失去部分能力（比如技能暂时失效）
- **深层路径**：有些路径只在深层世界存在，通过这些路径可以到达表层世界无法到达的区域

#### 两层世界的切换机制

- 古井是表层世界和深层世界的**通道**
- 进入古井 = 切换到深层世界视角
- 从古井出来 = 回到表层世界
- 赵大嘴不需要进入古井就能"看到"深层世界。这是他的特殊能力

### 关键机制

#### 1. 赵大嘴的灵视能力

赵大嘴能同时感知表层和深层两个世界。这是他之前没有意识到的能力。

**能力表现：**
- 他能看到深层世界的"路径"。告诉叶文轩"这边有路，虽然表面看起来是墙"
- 他能感知灵体的"活动规律"。比叶文轩的洞察之眼看到的更深层
- 他能感知红衣女人的"活动范围"。提前警告队友避开

**能力的限制：**
- 灵视消耗精神。长时间使用会导致头痛、注意力分散
- 灵视不能看到深层世界的全部。有些区域是"盲区"，赵大嘴也看不到

#### 2. 镜面机制

祠堂中的镜子是副本的**核心结构**。它是"规则核心"，是"真相接口"。

**镜面的功能：**
- 镜面是表层世界和深层世界的"接口"
- 镜面中显示的是"真相"。不只是小镇的过去，还有系统的影子
- 镜面碎裂后，两个世界的边界变弱。灵体更容易入侵表层世界

**镜面的三层内容：**

| 层次 | 内容 | 叶文轩看到什么 |
|------|------|------------|
| 第一层 | 小镇的过去 | 1937年的居民生活、日军入侵、全镇消失 |
| 第二层 | 系统的测试 | 系统在这个小镇测试环境引擎的过程 |
| 第三层 | 未来的碎片 | 叶文轩看到"未来的自己"。站在一个发光房间中 |

### 副本流程

#### 阶段1：入镇（0-30分钟）

**流程：**
1. 叶文轩和赵大嘴到达小镇入口
2. 白天探索。叶文轩分析房屋结构，赵大嘴"看"灵体世界
3. 发现茶馆，遇到王老头

**关键事件：**
- 赵大嘴的灵视初显。他"看到"了表层世界中没有的东西
- 王老头提供信息（话中有话）
- 叶文轩注意到镇上的时钟都停在3:17

#### 阶段2：入夜（30-90分钟）

**流程：**
1. 天黑，灵体开始活动
2. 叶文轩和赵大嘴找到一间安全的房子
3. 赵大嘴不小心看到了窗外的红衣女人

### 结构变化机制

#### 动态结构（定期变化）

书架定期重新排列，每次排列对应空间结构的变化。

**变化规律：**
- 结构变化遵循一个**数学序列**（斐波那契数列的变体）
- 叶文轩能通过观察前几次变化，**预测**下一次变化
- 但有一个"异常组"。某些书架的排列不遵循规律，像是被"固定"了

**变化类型：**

| 变化类型 | 示例 | 玩家应对 |
|----------|------|----------|
| 通道变化 | 某些走廊突然封闭或打开 | 改变路线 |
| 光源变化 | 某些区域的灯光突然熄灭或亮起 | 避开黑暗区域 |
| 巡逻变化 | 副本中的"巡逻者"（怪物）路线改变 | 重新分析巡逻模式 |
| 陷阱变化 | 某些区域出现或消失陷阱 | 用洞察之眼透视陷阱位置 |

#### 隐藏结构（叶文轩专属）

**D区。锁定的书架群：**
- 这组书架的排列不遵循数学序列。像是被系统"手动固定"
- 书架上的书的标题是"玩家专属"的。是通用信息
- 其中一本书的标题是：《闭环理论》
- 另一本书的标题是：《洞察者。锚点玩家的设计文档》
- 还有一本书的标题是：**《叶文轩》**（叶文轩自己的名字）

## 写作时的通用原则

### 危险呈现的方式

**不要写"你违反了XX规则所以死了"。** 危险应该通过以下方式呈现：
1. **怪物/敌人**。具体的、有形态的威胁，有攻击模式，可以被观察和分析
2. **环境陷阱**。可观察的、有触发条件的危险，可以通过谨慎避免
3. **结构变化**。环境结构的动态变化，需要玩家实时分析和适应
4. **NPC互动**。与副本中的NPC互动，理解他们的动机，找到通关路径

### 副本的"美感"

好的副本应该像一段**有逻辑的代码**：
- 有清晰的结构层次
- 有可识别的模式
- 有"意外"但不混乱
- 有"解法"但不简单

### 副本的"人性化"

副本不应该只是"障碍集合"。副本应该反映**主题**：
- 疗养院 = 沈知秋的"治疗理念"的具象化。怪物是她的"治疗者"，照明是她对"治愈"的控制
- 鬼镇 = 小镇居民的"集体恐惧"的具象化。灵体是恐惧的产物，镜面是真相的入口
- 图书馆 = 系统的"逻辑"的具象化。书架是结构，排列是规律，隐藏区域是真相

### Boss战的设计哲学

**不要设计"血厚的怪物"。** Boss战应该是"结构和模式的理解与应用"：
- 疗养院Boss = 照明操控战 + 逻辑说服（理解结构 → 操控结构 → 说服Boss）
- 鬼镇Boss = 对话与选择（理解双层结构 → 找到平衡点）
- 图书馆Boss = 结构预测（在变化中保持优势）

### 叶文轩的能力使用原则

**洞察之眼是"读攻略"。** 它是"分析结构模式"：
- 叶文轩能看到巡逻者的行为模式。但是通过观察得出规律
- 叶文轩能看到陷阱的结构弱点。但是通过分析找出触发条件
- 叶文轩能看到隐藏通道。但是通过透视出结构的缝隙

**这种能力的特点是：**
- 需要**观察和学习**。不是天生就能看到一切
- 有**精度限制**。早期只能看到粗略的模式，后期才能看到细节
- 有**认知负荷**。同时分析多个结构会消耗大量精神力。
