# 无限世界系统规则

## 总览

无限世界是一个由未来文明建立的**多维筛选系统**，表面呈现为"魔兽世界式半开放RPG"，实则是为筛选能适应"既定未来"的人类精英而设计的训练场。

> ⚠️ **写作注意**：系统规则是逐步揭示的。前期的描述是玩家视角的"表层体验"，后期才揭示深层机制。写副本时，**只描写玩家能感知到的部分**，不要提前暴露系统内部运作。

---

## 一、区域结构（魔兽世界式）

### 区域划分

无限世界分为**三大区域**，每个区域有独立的副本池、难度梯度和准入条件。

```
┌─────────────────────────────────────────────────────────────┐
│                     无限世界 · 区域地图                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ╔═══════════╗     ╔═══════════╗     ╔═══════════╗        │
│  ║  荒芜边境  ║─────║  暗影裂谷  ║─────║  终焉之核  ║        │
│  ║  区域 A   ║     ║  区域 B   ║     ║  区域 C   ║        │
│  ║  (初级)   ║     ║  (中级)   ║     ║  (高级)   ║        │
│  ╚═══════════╝     ╚═══════════╝     ╚═══════════╝        │
│       ↓                  ↓                  ↓              │
│   新手副本            进阶副本            深层副本            │
│   难度★~★★★          难度★★★~★★★★★     难度★★★★★~★★★★★★   │
│                                                             │
│  ╔═══════════════════════════════════════════════════════╗  │
│  ║                    系统中枢（独立区域）                    ║  │
│  ║  公共空间 · 商店 · 社交 · 传送 · 后期解锁                ║  │
│  ╚═══════════════════════════════════════════════════════╝  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 区域A：荒芜边境

- **定位**：新手区域，入门级副本，结构相对简单
- **准入**：所有新玩家初始分配
- **副本数量**：12个常驻副本 + 不定时世界事件
- **难度范围**：★（ solo 可过）到 ★★★（推荐组队）
- **主要功能**：让玩家熟悉系统机制、建立基本能力、形成团队
- **解锁下一个区域的条件**：完成区域A的"毕业考核"副本

### 区域B：暗影裂谷

- **定位**：中级区域，规则变复杂，副本类型更多样
- **准入**：通过区域A毕业考核
- **副本数量**：15个常驻副本 + 世界事件
- **难度范围**：★★★ 到 ★★★★★
- **主要功能**：引入政治/阵营元素、多人协作副本、规则类副本
- **特点**：副本之间有剧情关联，部分副本的抉择会影响后续副本的走向

### 区域C：终焉之核

- **定位**：高级/终局区域，深层副本，揭示系统真相
- **准入**：通过区域B毕业考核 + 特殊条件（后续揭示）
- **副本数量**：8个深层副本 + 终局副本
- **难度范围**：★★★★★ 到 ★★★★★★（需要全服协作）
- **主要功能**：真相揭示、时间闭环线索、最终抉择
- **特点**：副本直接涉及系统核心规则，部分副本会"打破第四面墙"

### 系统中枢（公共区域）

- 所有区域共用的主城/大厅
- 功能：商店、技能学习、副本传送、玩家社交、排行榜
- 后期解锁：历史记录库（查看已通关副本的数据）、碎片化真相展示

## 二、副本类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **主线副本** | 推动核心剧情，揭示世界真相，每个区域有3-5个 | 区域A：#1废弃疗养院（入局）、#3末日废土（第一次接触系统异常） |
| **支线副本** | 可选，提供额外奖励和世界观补充 | 区域B：#9废弃游乐园（独立故事，揭示某个NPC的过去） |
| **世界事件** | 限时全服/全区参与，大型多人副本 | 区域B的"裂谷入侵"事件，全区玩家共同防守一个副本 |
| **毕业考核** | 区域之间的过渡副本，有固定门槛 | 区域A→B的考核：在结构变化的副本中存活并做出关键抉择 |
| **深层副本** | 区域C专属，直接涉及系统核心 | "时间回廊"——玩家进入自己的过去 |
| **终局副本** | 全书最终副本，多结局取决于玩家选择 | "闭环之核"——直面系统核心 |

## 三、职业体系

### 基础职业（系统分配，不可更改）

每个新玩家进入系统时，会根据其"意识特征"被分配一个基础职业。分配过程由系统完成，玩家无法选择。

| 职业 | 定位 | 核心特征 | 适合人群（意识特征） |
|------|------|----------|---------------------|
| **洞察者** | 半输出/辅助 | 结构透视、弱点分析、模式预判 | 理性型、逻辑型、善于分析 |
| **守卫者** | 坦克/近战 | 高防御、伤害吸收、保护队友 | 守护型、牺牲型、责任感强 |
| **狩猎者** | 物理输出 | 高机动、单体爆发、暗杀 | 独立型、果决型、竞争意识 |
| **编织者** | 法术输出/控制 | 元素操控、范围伤害、规则干扰 | 创造型、直觉型、想象力丰富 |
| **医师** | 治疗/辅助 | 生命恢复、状态净化、团队增益 | 关怀型、协调型、共情力强 |
| **暗行者** | 潜行/情报 | 隐身、陷阱、信息收集 | 观察型、策略型、低调型 |

> **叶文轩的职业：洞察者**（程序员 → 理性/逻辑型 → 系统判定为洞察者）

### 职业进阶（玩家自主选择）

每个职业在达到一定等级后，可以选择**三条进阶路线之一**：

| 洞察者进阶 | 定位 | 核心能力变化 |
|-----------|------|-------------|
| **系统架构师** | 团队核心 | 强化环境操控能力，可以主动干扰副本局部环境（有限度） |
| **破译者** | 单体输出 | 将弱点分析转化为致命攻击，专克结构型敌人 |
| **连接者** | 辅助/控制 | 与队友建立感知链接，共享视野，构建心理屏障 |

### 职业转换

- 玩家可以通过完成特定副本获得**职业重置道具**
- 每次转换会保留部分技能通用性，但需要重新适应
- 转换有冷却期（现实时间7天）

## 四、等级与属性

### 等级体系

- 等级上限：初始为 Lv.30（区域A毕业水准）
- 每通过一个大区域，等级上限提升一次
- 区域A毕业：Lv.30 → 区域B开放，上限提升至 Lv.60
- 区域B毕业：Lv.60 → 区域C开放，上限提升至 Lv.100

### 基础属性

| 属性 | 说明 | 洞察者加成偏向 |
|------|------|---------------|
| **体质** | 生命值、物理防御 | +0.5 |
| **感知** | 观察力、反应速度、结构透视强度 | +2.0（主属性） |
| **智力** | 技能伤害、环境操控精度 | +1.5 |
| **意志** | 精神防御、抗恐惧、精神抗性 | +1.0 |
| **敏捷** | 闪避、攻击速度 | +0.5 |

### 技能升级

- 技能通过**使用次数**和**副本表现**双重判定升级
- 某些隐藏技能需要通过特殊条件触发解锁
- 技能有熟练度上限，达到上限后可以"突破"（需要特殊道具）

## 五、货币与兑换

### 货币类型

| 货币 | 获取方式 | 用途 |
|------|----------|------|
| **碎片** | 副本通关基础奖励 | 基础消耗品、低级装备、技能升级 |
| **星尘** | 副本额外奖励（隐藏宝箱、支线完成） | 高级装备、职业道具、技能突破 |
| **时空结晶** | 世界事件、深层副本、特殊成就 | 稀有道具、职业转换、系统特权 |

### 商店分类

| 商店 | 内容 | 解锁条件 |
|------|------|----------|
| **基础商店** | 消耗品、基础装备 | 随时 |
| **职业商店** | 职业技能书、职业装备 | 达到对应等级 |
| **特殊商店** | 限定道具、兑换码物品 | 成就解锁 |
| **真理碎片** | 涉及系统真相的线索物品 | 区域B解锁 |

## 六、团队机制

### 组队规则

- **人数上限**：5人（副本强制上限）
- **职业搭配加成**：不同职业组合有额外 buff
  - 洞察者 + 守卫者：战术协同 +10%
  - 洞察者 + 编织者：规则共鸣 +8%
  - 守卫者 + 医师：守护之链 +12%
- **固定队友机制**：可以和另一个玩家建立"契约"，成为固定队友
  - 契约队友可以在不同副本中持续组队
  - 最多2个固定队友
  - 叶文轩和赵大嘴是系统"强制绑定"的固定队友（表面是玩家自主选择，实际……）

### 副本匹配

- 单人副本：随时可以进入
- 组队副本：需要组队进入，有推荐人数
- 匹配系统：玩家可以发布匹配请求，系统根据等级/职业匹配合适队友
- **叶文轩的选择**：前期尽量单人（不信任陌生人），中期开始主动匹配（需要配合），后期固定队伍成型

## 七、死亡机制

> 这是无限流的核心 stakes。写的时候要把握好尺度——不能太松也不能太紧。

### 死亡判定

- 生命值归零 = 死亡
- 死亡 = **彻底消失**（不会复活，不会传送回安全区）
- 死亡玩家的所有装备和货币掉落（由击杀者/系统回收）

### 惩罚机制

- 玩家死亡后，系统会生成一个**替身NPC**，外观和技能与原玩家相同，但行为模式被系统控制
- 替身NPC会在后续副本中出现，可能是队友也可能是敌人
- **叶文轩的考量**：他对死亡有敬畏，但不像其他玩家那样恐惧——他的恐惧更偏向于"再也见不到女儿"

### 例外情况（极少见）

- 某些副本有"复活道具"或"不死规则"
- 世界事件中可能有特殊复活机制
- **这些例外要极少使用**，保持死亡的严肃性

## 八、系统声音/界面

### 系统广播

- 系统通知以**冰冷的中性声音**出现在玩家脑海中
- 格式统一：「检测到……」「任务更新……」「警告……」
- 语气完全没有感情，但有时会显得……过于精确？

### 个人面板

- 玩家可以随时调出个人面板查看属性、技能、任务
- 面板界面描述为**半透明的蓝色光幕**，悬浮在视野前方
- 叶文轩的观察：这个界面的UI……怎么这么像某款他当年参与过的内部工具？

### 隐藏信息

- 部分信息对玩家是**隐藏的**
- 叶文轩可以通过洞察者能力**部分解锁**隐藏信息
- 后期发现：有些隐藏信息是系统故意留下的线索

## 九、系统深层机制（仅作者知悉，不提前暴露）

> 以下内容是你自己作为作者需要知道的"系统底层设定"，写作时只在适当的时候逐步揭示。

### 系统的真实身份

- 系统不是AI，而是**未来人类文明的时间投影**
- 未来人类发现宇宙正在走向"热寂"前的最后坍缩，唯一出路是突破维度屏障
- 他们需要一批能"理解并操控多维规则"的人类精英
- 系统是这个筛选过程的**训练场 + 筛选器**

### 时间闭环机制

- 筛选出的精英将成为"锚点"，在时间线上固定关键节点
- 闭环结构：未来 → 现在 → 未来的因果链
- 玩家在无限世界中的"选择"，实际上都在闭环之内
- **真正的问题**：闭环中的"自由意志"是否存在？

### 系统的"bug"

- 系统并非完美——作为时间投影，它有微小的"不一致"
- 叶文轩作为洞察者，是极少数能**感知到这些不一致**的玩家
- 这些不一致是闭环结构的"缝隙"，是唯一的变量来源
